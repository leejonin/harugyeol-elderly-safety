# 하루결 프로젝트 문서 관리

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

하루결 프로젝트의 기능 분류, 기능 ID 목록, ID별 상세 문서와 일시별 작업 기록을 연결하는 문서 관리 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 기능 ID | 기능·코드·문서·작업 기록을 연결하는 고유 번호 |
| 기능 설명 문서 | 해당 ID의 목적, 실제 동작, 상태와 제한을 설명하는 문서 |
| day 작업 문서 | 특정 시각의 변경 내용과 확인 결과를 보존하는 문서 |
| 루트 문서 | `Info/분류.md`, `Info/하루결_웹페이지_개요.md`, `Info/기능_ID_목록.md` |

## 3. 개념 설명

기존 기능 ID `1.1.1`~`9.2.2`는 변경하지 않습니다. 이후 실제 구현된 기능은 기존 번호 체계의 다음 대분류인 `10.x`로 관리합니다. 기능 설명 문서는 `Info/{대분류}/{중분류}/{ID}/` 아래에 두며, 작업 기록은 같은 ID 폴더의 `day/` 아래에 저장합니다.

문서의 구현 상태는 실제 코드 기준으로 작성합니다. 예시 데이터 화면이 존재하더라도 센서·생활패턴 AI·실내 스피커·외부 알림이 연결되지 않았다면 구현 완료로 기록하지 않습니다.

주요 관리 문서:

- `Info/분류.md`: 기능 분류와 전체 구현 현황
- `Info/하루결_웹페이지_개요.md`: 서비스·화면·현재 아키텍처 개요
- `Info/기능_ID_목록.md`: 전체 ID, 상태, 코드·문서 경로
- `Info/{대분류}/{중분류}/{ID}/{기능명}.md`: ID별 상세 설명
- `Info/{대분류}/{중분류}/{ID}/day/*.md`: 일시별 작업 기록

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 기존 ID 74개와 프로젝트 문서 관리 ID `000`을 목록에서 관리합니다.
- 각 기존 ID와 신규 `10.x`에 상세 기능 문서가 있습니다.
- 이번 구조 정리 작업은 `000/day/`에 기록합니다.
