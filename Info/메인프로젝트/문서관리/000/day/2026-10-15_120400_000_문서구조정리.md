## 1. 개요

ForAgents 0.0.4 지침에 따라 하루결 프로젝트 문서를 기존 기능 ID 중심 구조로 정리하고 현재 코드의 실제 구현 상태를 기록했습니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 문서 구조 정리 | 기존 문서를 보존하면서 ID별 기능 문서와 통합 목록을 추가하는 작업 |
| 구현 중 | UI 또는 시연 동작은 있으나 기능 정의의 전체 범위나 실제 연동이 완료되지 않은 상태 |
| 미구현 | 계획과 문서만 있고 실행 코드가 없는 상태 |

## 3. 개념 설명

기존 `분류.md`의 ID를 우선 적용했습니다. 새로 구현된 GPT 대화, 브라우저 음성 읽기, GitHub Pages 배포는 다음 순번인 `10.x`로 추가했습니다. 기존 루트 문서는 삭제·이동하지 않고 현재 상태와 문서 링크를 보강했습니다.

## 4. 작업 내용

1. `Info/분류.md`에 문서 생성·수정 일시, 신규 `10.x`, 구현 현황, 수정 전후와 ID 연결을 추가했습니다.
2. `Info/하루결_웹페이지_개요.md`에 용어, AI 대화·TTS·배포 구조, 구현 제한, 수정 전후와 관련 ID를 추가했습니다.
3. `Info/기능_ID_목록.md`를 생성해 전체 기능의 상태, 코드 경로, 문서 경로를 기록했습니다.
4. `Info/{대분류}/{중분류}/{ID}/` 아래에 ID별 기능 설명 문서를 생성했습니다.
5. 센서·생활패턴 AI·실내 스피커·외부 알림의 예시 화면을 실제 연동 완료로 표기하지 않았습니다.
6. 상세 문서와 기능 ID 목록의 상태를 `미구현`, `구현 중`, `구현 완료`로 통일하고 ID별 상태를 대조했습니다.
