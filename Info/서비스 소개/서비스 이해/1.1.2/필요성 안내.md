# 필요성 안내

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

노인 안전관리 서비스가 필요한 배경을 서비스 소개 화면에 설명하는 웹 안내 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 사고 발견 지연 | 사고나 이상 상황이 발생해도 주변에서 즉시 알기 어려운 상황 |
| 상시 확인 | 보호자가 지속적으로 어르신의 상태를 직접 확인하는 행위 |
| 생활 흐름 변화 | 평소 생활 리듬과 달라진 가전 사용·문 열림·움직임 등의 변화 |

## 3. 개념 설명

`index.html`의 `필요성` 영역에서 사고 발견 지연 가능성, 보호자의 상시 확인이 어려운 현실, 평소 생활 흐름 변화를 조기에 파악할 필요를 목록으로 표시합니다. 내용은 정적 안내이며 위험 감소 효과를 계산하거나 검증하는 기능은 아닙니다.

주요 코드 경로:

- `index.html`: 필요성 제목과 세 가지 안내 항목 표시
- `js/common.js`: 시연 데이터 및 연동 제한 배너 표시
- `css/style.css`: 소개 섹션 공통 스타일

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 서비스 소개 화면에서 필요성 안내 문구를 정적으로 표시합니다.
- 제한: 통계 분석, 사고 예측 또는 실제 안전 효과 검증 기능은 포함하지 않습니다.
