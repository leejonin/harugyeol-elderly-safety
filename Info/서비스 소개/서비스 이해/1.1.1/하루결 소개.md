# 하루결 소개

- 문서 초기 생성 일시: 2026-10-15 12:04 KST

## 1. 개요

하루결의 서비스명과 핵심 소개 문구를 방문자에게 표시하는 웹 안내 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 하루결 | 카메라 대신 생활 신호를 활용해 평소와 다른 변화를 확인하는 노인 안전관리 서비스명 |
| 소개 문구 | 서비스의 목적과 방식을 한 문장으로 설명하는 문구 |
| 시연 화면 | 실제 센서·생활패턴 AI가 연결되지 않은 웹 시연 환경 |

## 3. 개념 설명

`index.html`의 첫 화면에 서비스명 `하루결`과 “카메라 없이 생활 신호를 분석하고, 평소와 다른 변화가 나타나면 먼저 안부를 확인하는 AI 노인 안전관리 서비스”라는 소개 문구를 정적으로 표시합니다. 공통 헤더는 모든 표시 데이터가 예시이며 센서·AI·스피커·외부 알림이 미연동임을 함께 알립니다.

주요 코드 경로:

- `index.html`: 서비스명과 한 문장 소개 표시
- `js/common.js`: 시연 배너와 공통 헤더 표시
- `js/pages/intro.js`: 소개 화면의 연동 상태 태그 표시
- `css/style.css`: 소개 영역과 공통 화면 스타일

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 정적 웹에서 서비스명과 소개 문구를 표시합니다.
- 제한: 소개 문구는 서비스 개념 안내이며 실제 센서 수집이나 생활패턴 AI 동작을 의미하지 않습니다.
