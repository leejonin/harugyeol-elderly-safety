# 이용 대상 안내

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

하루결의 예상 이용 대상을 어르신 가구, 가족·보호자, 관리기관·요양시설로 나누어 안내하는 웹 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 어르신 가구 | 가정에서 생활하며 안전 확인 대상이 되는 어르신 측 이용 대상 |
| 가족·보호자 | 생활 상태와 알림을 확인하고 대응하는 사용자 |
| 관리기관·요양시설 | 담당 어르신의 확인 필요 상황과 대응 내역을 관리하는 조직 |

## 3. 개념 설명

`index.html`의 `이용 대상` 영역은 세 개의 카드로 이용 대상과 각 대상의 이용 목적을 정적으로 표시합니다. 실제 사용자 등록, 권한 부여 또는 기관 연계 동작은 이 기능의 범위가 아닙니다.

주요 코드 경로:

- `index.html`: 이용 대상별 카드와 설명 표시
- `css/style.css`: `intro-grid`, `intro-card` 기반 카드 배치
- `js/common.js`: 시연 배너와 공통 헤더 표시

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 세 이용 대상과 목적을 반응형 카드로 표시합니다.
- 제한: 대상 등록 및 실제 기관·보호자 연결은 수행하지 않는 정적 안내입니다.
