# 개인별 확인 과정 안내

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

대상자별 평소 리듬을 기준으로 순차 확인하여 불필요한 알림을 줄인다는 서비스 목표를 설명하는 웹 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 개인별 확인 기준 | 모든 대상자에게 같은 기준을 적용하지 않고 각자의 평소 리듬을 고려한다는 개념 |
| 순차 확인 | 본인, 가족, 보호자·기관 순서로 확인하도록 계획된 과정 |
| 불필요한 알림 감소 | 개인별 비교와 단계별 확인을 통해 달성하려는 목표이며 현재 검증된 결과는 아님 |

## 3. 개념 설명

`index.html`의 `개인별 확인 과정` 카드에서 어르신마다 다른 평소 리듬을 기준으로 순차 확인한다고 설명합니다. 문구는 “불필요한 알림을 줄이는 것을 목표”로 표현하며, 현재 코드에는 목표 달성률 측정이나 실제 개인별 판단 엔진이 없습니다.

주요 코드 경로:

- `index.html`: 개인별 확인 과정과 목표 문구 표시
- `js/common.js`: AI 분석·스피커·외부 알림 미연동 표시
- `js/data.js`: 화면 시연용 개인별 기준과 단계 상태
- `css/style.css`: 서비스 특징 카드 표시

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 개인별 기준과 순차 확인이라는 서비스 특징을 정적으로 안내합니다.
- 제한: 실제 기준 학습, 알림 감소 검증, 자동 순차 대응은 구현되지 않았습니다.
