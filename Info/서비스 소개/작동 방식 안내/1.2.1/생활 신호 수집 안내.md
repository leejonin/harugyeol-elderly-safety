# 생활 신호 수집 안내

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

스마트 플러그·문 열림 센서·움직임 센서를 생활 신호 수집 수단으로 설명하는 웹 안내 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 생활 신호 | 가전 사용, 문 열림, 실내 움직임처럼 일상 흐름을 간접적으로 나타내는 기록 |
| 스마트 플러그 | 가전의 전력 사용 여부를 확인하는 장치로 계획된 센서 |
| 시연 데이터 | 실제 센서 수신값이 아니라 `js/data.js`에 정의된 예시 기록 |

## 3. 개념 설명

`index.html`의 `작동 방식` 첫 단계에서 세 센서 종류와 수집 역할을 정적으로 안내합니다. 소개 페이지의 연동 상태 태그와 공통 시연 배너는 센서가 실제로 연결되지 않았음을 명시합니다.

주요 코드 경로:

- `index.html`: 생활 신호 수집 단계와 센서 종류 안내
- `js/pages/intro.js`: 센서 미연동 태그가 포함된 연동 상태 영역 표시
- `js/common.js`: 센서 연동 상태를 `false`로 정의하고 시연 배너 표시
- `js/data.js`: 실제 수신값이 아닌 시연용 생활 신호 예시

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 생활 신호 수집 방식에 대한 웹 설명을 표시합니다.
- 제한: 안내 기능만 완료되었습니다. 실제 스마트 플러그·문 열림·움직임 센서 수신 기능은 `3.1.1`~`3.1.3` 기준 미구현입니다.
