# 단계별 대응 안내

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

본인 안부 확인에서 가족 확인, 보호자·기관 연결로 이어지는 순차 대응 개념을 설명하는 웹 안내 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 본인 안부 확인 | 이상 변화가 있을 때 어르신에게 먼저 상태를 묻도록 계획된 단계 |
| 가족 확인 | 본인 응답이 없거나 변화가 지속될 때 가족에게 확인을 요청하는 단계 |
| 기관 연결 | 위험이 커졌다고 판단될 때 등록 보호자 또는 관리기관에 연결하도록 계획된 단계 |

## 3. 개념 설명

`index.html`의 `작동 방식` 세 번째 단계는 `본인 안부 확인 → 가족 확인 → 보호자·기관 연결` 순서를 정적으로 표시합니다. 현재 알림 화면에는 이 흐름의 시연 이력이 있으나, 실내 스피커·외부 알림·기관 연계는 실제로 동작하지 않습니다.

주요 코드 경로:

- `index.html`: 단계별 대응 순서 안내
- `js/common.js`: 스피커와 외부 알림의 미연동 상태 표시
- `js/data.js`: 단계별 대응을 보여 주는 시연용 알림 이력
- `js/pages/alerts.js`: 시연 대응 이력 표시

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 서비스가 지향하는 단계별 대응 순서를 웹 문구로 안내합니다.
- 제한: 안내 기능만 완료되었고, 스피커 질문·가족 알림 전달·기관 연결은 실제 연동되지 않았습니다.
