# 개인별 분석 안내

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

개인의 평소 생활패턴과 현재 기록을 비교하는 서비스 개념을 설명하는 웹 안내 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 개인별 기준 | 대상자마다 다른 평소 생활 리듬을 비교 기준으로 삼는 서비스 개념 |
| 현재 기록 | 비교 대상이 되는 최근 가전 사용·문 열림·움직임 기록 |
| 생활패턴 AI | 기록을 학습하고 변화를 판단하도록 계획된 분석 기능으로, 현재 실제 엔진은 미구현 |

## 3. 개념 설명

`index.html`의 `작동 방식` 두 번째 단계에서 평소 생활패턴과 현재 기록을 비교한다고 설명합니다. 이는 서비스 설계 안내이며, 현재 웹에는 개인별 학습이나 변화 판단 알고리즘이 없습니다. 화면에 보이는 기준과 결과는 `js/data.js`의 시연 데이터입니다.

주요 코드 경로:

- `index.html`: 개인별 분석 단계 설명
- `js/common.js`: AI 분석 미연동 태그와 시연 배너 표시
- `js/data.js`: 시연용 기준 구간과 상태 값
- `js/pages/pattern.js`: 시연 기준과 현재 기록의 화면 시각화

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 개인별 분석 개념을 정적 웹 문구로 표시합니다.
- 제한: 안내 기능만 완료되었습니다. 개인별 기준 학습과 실제 변화 분석은 구현되지 않았습니다.
