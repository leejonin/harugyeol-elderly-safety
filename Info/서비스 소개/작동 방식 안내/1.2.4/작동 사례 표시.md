# 작동 사례 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

아침 전기포트 미사용과 실내 움직임 미감지가 함께 나타나는 가상 사례로 서비스 작동 흐름을 설명하는 웹 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 작동 사례 | 서비스 개념 이해를 위해 제시하는 가상 상황 |
| 복합 생활 변화 | 서로 다른 종류의 생활 변화가 함께 나타난 상태 |
| 미감지 | 센서 데이터가 수신되었으나 해당 활동 기록이 없는 것으로 표현한 상태 |

## 3. 개념 설명

`index.html`은 평소 아침에 사용하던 전기포트 기록이 없고 오전 움직임도 감지되지 않은 상황을 가정하여, 스피커 질문과 가족·기관 확인으로 이어지는 흐름을 설명합니다. 같은 내용이 `js/data.js`의 시연 신호와 알림 사유에도 예시로 들어 있으나 실제 센서나 AI가 생성한 결과는 아닙니다.

주요 코드 경로:

- `index.html`: 작동 사례 설명 문단
- `js/data.js`: 전기포트 미사용·움직임 미감지 시연 기록과 알림 사유
- `js/pages/dashboard.js`: 시연 신호와 알림 사유 표시
- `js/common.js`: 센서·AI·스피커·외부 알림 미연동 배너

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 가상 사례를 정적 문구로 표시하고 동일한 시연 데이터를 관련 화면에서 보여 줍니다.
- 제한: 사례는 실제 감지·분석·대응 결과가 아니며 기준값이나 위험 판단 로직도 구현되지 않았습니다.
