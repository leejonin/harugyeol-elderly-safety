# 8.3.1 예시 데이터 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

웹 화면의 대상자·생활 신호·알림·기기 정보가 실제 운영 기록이 아닌 시연 데이터임을 명시하는 기능입니다.

## 2. 용어 정의

- 시연 데이터: 화면 동작 확인을 위해 `js/data.js`가 실행 시점에 생성하는 예시 데이터입니다.
- 시연 배너: 각 페이지 상단에서 데이터와 연동 상태의 한계를 알리는 안내 영역입니다.

## 3. 개념 설명

공통 헤더는 모든 주요 화면에 `시연 화면` 안내와 센서·AI·스피커·외부 알림이 미연동이라는 문구를 표시합니다. 설정과 로그인 화면에도 예시·시연 입력임을 별도로 안내합니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 공통 시연 배너와 화면별 안내 문구로 예시 데이터임을 사용자에게 표시합니다.
- 제한: 사용자가 브라우저 `localStorage`에서 수정한 값도 운영 서버 데이터가 아니며 브라우저별로만 유지됩니다.
- 주요 코드 경로: `js/common.js`, `js/data.js`, `login.html`, `settings.html`, `js/pages/dashboard.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 공통 배너와 화면별 안내를 통해 예시 데이터임을 표시하는 현재 동작과 저장 범위를 기록
- 변경 이유: 시연 값과 실제 생활 기록의 혼동을 방지하기 위해 최초 문서화
- 관련 파일: `js/common.js`, `js/data.js`, `login.html`, `settings.html`, `js/pages/dashboard.js`

- 관련 기능 ID: `2.2.3`, `3.2.2`, `8.3.2`
