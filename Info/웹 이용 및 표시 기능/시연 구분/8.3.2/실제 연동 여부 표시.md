# 8.3.2 실제 연동 여부 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

센서·생활패턴 AI·실내 스피커·외부 알림과 GPT 대화의 실제 연동 여부를 구분해 표시하는 기능입니다.

## 2. 용어 정의

- 미연동: 외부 장치나 서비스와 실제 데이터를 송수신하지 않는 상태입니다.
- GPT 연동: 브라우저에 유효한 형식의 API 키가 저장되고 목 모드가 꺼진 설정 상태입니다.

## 3. 개념 설명

공통 연동 태그는 센서, AI 분석, 스피커와 외부 알림을 항상 미연동으로 표시합니다. GPT 대화는 API 키 저장 여부와 목 모드 설정에 따라 태그와 채팅 상태 문구가 달라집니다. 이 표시는 스피커 연동과 브라우저 TTS를 구분합니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 대시보드와 설정 화면에서 외부 연동 상태를 표시하고 AI 대화 화면에서 GPT 연결·목 응답 상태를 표시합니다.
- 제한: 센서·AI 분석·실내 스피커·외부 알림은 실제 미연동입니다. GPT 키 저장 표시는 연결 가능 설정을 뜻하며 API 요청 성공 자체를 보장하지 않습니다.
- 주요 코드 경로: `js/common.js`, `js/pages/dashboard.js`, `js/pages/settings.js`, `js/pages/chat.js`, `js/llm/harugyeol-llm.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 미연동 외부 기능과 선택적 GPT API 연결 상태를 구분하는 현재 표시 동작과 한계를 기록
- 변경 이유: 시연 UI와 실제 연동 범위를 명확히 하기 위해 최초 문서화
- 관련 파일: `js/common.js`, `js/pages/dashboard.js`, `js/pages/settings.js`, `js/pages/chat.js`, `js/llm/harugyeol-llm.js`
