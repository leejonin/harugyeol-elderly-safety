# 8.1.1 로그인·로그아웃

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

보호자와 관리 담당자가 시연 계정을 선택해 접속하고 세션을 종료하는 기능입니다.

## 2. 용어 정의

- 시연 계정: 비밀번호 인증 없이 코드에 미리 정의된 보호자 또는 기관 담당자 계정입니다.
- 시연 세션: 선택한 사용자의 ID·이름·역할을 브라우저 `localStorage`에 저장한 값입니다.

## 3. 개념 설명

로그인 화면에서 예시 계정을 선택하면 세션을 저장하고 대시보드로 이동합니다. 보호 화면은 세션이 없으면 로그인 화면으로 이동하며 공통 헤더의 로그아웃 버튼은 세션을 삭제합니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 적용 범위: **정적 웹 시연**
- 실제 동작: 시연 계정 로그인, 보호 페이지 이동 제어 및 로그아웃이 동작합니다.
- 제한: 비밀번호, 서버 세션, 사용자 가입, 실제 인증·인가 및 보안 토큰은 없습니다.
- 주요 코드 경로: `login.html`, `js/pages/login.js`, `js/common.js`, `js/data.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 시연 계정 기반 로그인·로그아웃은 동작하지만 실제 인증 시스템이 아니라는 내용을 기록
- 변경 이유: 시연 세션과 운영 계정 인증을 구분하기 위해 최초 문서화
- 관련 파일: `login.html`, `js/pages/login.js`, `js/common.js`, `js/data.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `8.1.1`
- 관련 기능 ID: `2.1.1`, `8.1.2`
