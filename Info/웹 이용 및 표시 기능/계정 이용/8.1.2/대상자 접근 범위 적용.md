# 8.1.2 대상자 접근 범위 적용

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

로그인한 사용자에게 연결된 어르신 정보만 조회·처리하도록 시연 화면의 범위를 제한하는 기능입니다.

## 2. 용어 정의

- `elderIds`: 시연 사용자에게 연결된 대상자 ID 목록입니다.
- 클라이언트 측 제한: 브라우저 JavaScript가 화면에 표시할 데이터를 필터링하는 방식입니다.

## 3. 개념 설명

공통 유틸리티가 세션 사용자와 시드 사용자의 `elderIds`를 연결해 접근 가능한 대상자 목록을 반환합니다. 대시보드, 알림, 설정 및 AI 대화 화면은 이 목록으로 데이터를 제한합니다. 생활패턴 화면의 선택 목록은 제한되지만 URL의 `elder` 값을 접근 목록과 대조하지 않습니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 시연 로그인 사용자별 대상자 목록 필터가 주요 화면에 적용되고 알림 상세는 접근 권한도 검사합니다.
- 제한: `pattern.html?elder=...`의 쿼리 대상자를 접근 목록과 검증하지 않는 경로가 있습니다. 데이터와 권한이 모두 클라이언트에 있어 조작 가능하며 서버 측 인가나 실제 계정 권한 검증도 없습니다.
- 주요 코드 경로: `js/common.js`, `js/data.js`, `js/pages/dashboard.js`, `js/pages/pattern.js`, `js/pages/alerts.js`, `js/pages/settings.js`, `js/pages/chat.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 시연 화면의 대상자 필터 적용 범위, 생활패턴 URL 검증 누락 및 서버 인가 부재를 기록
- 변경 이유: 화면 필터링과 실제 접근 통제의 차이를 코드 동작에 맞게 명확히 하기 위해 최초 문서화
- 관련 파일: `js/common.js`, `js/data.js`, `js/pages/dashboard.js`, `js/pages/pattern.js`, `js/pages/alerts.js`, `js/pages/settings.js`, `js/pages/chat.js`
