# 8.2.2 상태 문구 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

색상에만 의존하지 않고 명확한 문구와 함께 확인 상태를 표시하는 기능입니다.

## 2. 용어 정의

- 상태 코드: `check_needed`, `data_not_received` 등 화면 상태를 식별하는 값입니다.
- 상태 배지: 상태 문구와 시각적 스타일을 함께 제공하는 HTML 요소입니다.

## 3. 개념 설명

공통 `STATUS_MAP`이 상태 코드별 한국어 문구와 스타일 클래스를 정의하고 `renderStatusBadge`가 `role="status"` 배지를 생성합니다. 확인 필요, 데이터 부족, 움직임 미감지, 데이터 미수신 및 기기 연결 이상을 서로 다른 문구로 표시합니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 대시보드·생활패턴·알림에서 색상과 상태 문구를 함께 표시하고 데이터 미수신과 움직임 미감지를 구분합니다.
- 제한: 상태 값 자체는 주로 예시 데이터이므로 실제 안전 여부나 장치 상태를 확정하지 않습니다.
- 주요 코드 경로: `js/common.js`, `css/style.css`, `js/pages/dashboard.js`, `js/pages/pattern.js`, `js/pages/alerts.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 공통 상태 문구와 배지 표시가 구현되었으며 입력 상태는 시연 값이라는 제한을 기록
- 변경 이유: 색상과 문구의 역할 및 상태 해석 범위를 최초 문서화
- 관련 파일: `js/common.js`, `css/style.css`, `js/pages/dashboard.js`, `js/pages/pattern.js`, `js/pages/alerts.js`
