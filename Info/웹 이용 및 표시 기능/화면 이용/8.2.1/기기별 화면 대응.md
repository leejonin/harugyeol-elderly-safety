# 8.2.1 기기별 화면 대응

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

PC와 모바일 화면에서 상태·알림·설정·대화 내용을 읽고 조작할 수 있도록 배치를 조정하는 기능입니다.

## 2. 용어 정의

- 반응형 화면: 화면 너비에 따라 열 배치, 메뉴 및 여백을 바꾸는 웹 화면입니다.
- 모바일 하단 메뉴: 작은 화면에서 대시보드·생활패턴·알림·설정으로 이동하는 고정 메뉴입니다.

## 3. 개념 설명

모든 HTML 문서가 viewport 메타 태그와 공통 스타일을 사용합니다. `768px` 이하에서는 분할 레이아웃을 한 열로 바꾸고 모바일 메뉴, 스크롤 가능한 표, 채팅 설정 사이드바와 입력 영역을 작은 화면에 맞게 조정합니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 공통 페이지와 AI 대화 화면에 PC·모바일 반응형 스타일 및 모바일 탐색 요소가 적용됩니다.
- 제한: 브라우저·운영체제별 실제 기기 검증 범위는 별도 자동 테스트로 관리되지 않으며 정적 웹 UI에 한정됩니다.
- 주요 코드 경로: `css/style.css`, `js/common.js`, `index.html`, `dashboard.html`, `pattern.html`, `alerts.html`, `settings.html`, `chat.html`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 반응형 레이아웃, 모바일 탐색 및 가로 스크롤 표 등 현재 적용 요소와 검증 제한을 기록
- 변경 이유: 기기별 화면 대응의 실제 코드 범위를 최초 문서화
- 관련 파일: `css/style.css`, `js/common.js` 및 각 HTML 페이지
