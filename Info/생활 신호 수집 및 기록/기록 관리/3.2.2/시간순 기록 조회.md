# 시간순 기록 조회

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

선택 대상자의 생활 신호를 발생 시각 순서로 정렬하여 표로 표시하는 웹 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 시간순 기록 | 신호의 `at` 값을 기준으로 과거에서 최근 순으로 정렬한 목록 |
| 생활 신호 종류 | 가전 `plug`, 문 열림 `door`, 움직임 `motion` |
| 시연 기록 | `js/data.js`가 페이지 로드 시 생성하는 예시 신호 |

## 3. 개념 설명

생활패턴 상세 화면은 선택한 대상자의 신호를 필터링하고 `Date` 값의 오름차순으로 정렬합니다. 표에는 시각, 한글 종류, 설명을 표시하며 조건에 맞는 값이 없으면 빈 결과 안내를 표시합니다.

주요 코드 경로:

- `pattern.html`: 생활패턴 상세 화면 진입점
- `js/pages/pattern.js`: 대상자별 필터, 시간 오름차순 정렬, 표 렌더링
- `js/data.js`: 조회 대상인 시연 신호
- `js/common.js`: 시각 형식 변환과 접근 범위 처리

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: **시연 데이터 기준**으로 생활 신호를 시각 오름차순 표로 조회합니다.
- 제한: 실제 센서 기록이나 서버 페이지네이션·대량 조회가 없으며 새 신호의 실시간 반영도 없습니다.
