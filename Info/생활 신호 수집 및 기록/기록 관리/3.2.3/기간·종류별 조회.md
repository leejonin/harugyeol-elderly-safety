# 기간·종류별 조회

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

날짜 기간과 센서 종류를 기준으로 생활 신호를 조회하도록 정의된 웹 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 종류 필터 | 전체, 가전, 문 열림, 움직임 중 하나를 선택하는 조건 |
| 기간 필터 | 시작일과 종료일로 조회 범위를 제한하는 조건 |
| 쿼리 값 | URL의 `kind` 값으로 현재 종류 선택을 유지하는 방식 |

## 3. 개념 설명

현재 생활패턴 화면에는 센서 종류 선택기가 있고 `kind` 쿼리 값에 따라 시연 신호를 필터링합니다. 대상자 선택과 종류 선택이 바뀌면 쿼리를 포함한 URL로 이동합니다. 날짜 또는 시작·종료 기간을 입력하거나 적용하는 UI와 로직은 없습니다.

주요 코드 경로:

- `js/pages/pattern.js`: 종류 선택기, `kind` 쿼리 처리, 종류별 필터
- `pattern.html`: 조회 화면 진입점
- `js/data.js`: 필터 대상 시연 신호
- 기간 필터 구현 코드: 없음

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 전체·가전·문 열림·움직임 종류별 조회가 동작합니다.
- 제한: 기능명에 포함된 날짜·기간별 조회는 미구현이며 실제 센서 기록 조회 API도 없습니다.
