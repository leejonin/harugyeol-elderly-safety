# 대상자별 기록 저장

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

수신한 생활 신호를 해당 어르신과 기기에 연결하여 저장하도록 계획된 데이터 관리 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 대상자 연결 | 생활 신호에 `elderId`를 부여해 어르신을 식별하는 구조 |
| 기기 연결 | 수신 기록을 발생 장치와 추적 가능하게 연결하는 구조 |
| 영구 저장 | 브라우저 세션을 넘어 서버 또는 데이터베이스에 기록을 보존하는 처리 |

## 3. 개념 설명

시연 신호 객체에는 `elderId`, 시각, 종류, 설명이 있으나 실제 수신 데이터를 만드는 흐름은 없습니다. 신호 객체에는 발생 기기 ID가 없으며, `Data.saveStore()`의 저장 대상에도 `signals`가 포함되지 않습니다. 따라서 브라우저 `localStorage`에도 생활 신호를 새로 저장하는 기능이 없습니다.

주요 코드 경로:

- 실제 기록 저장 구현 코드: 없음
- `js/data.js`: 시연용 `signals` 구조, `getStore()` 및 `saveStore()`
- `js/pages/dashboard.js`: 시연 신호의 대상자별 조회
- `js/pages/pattern.js`: 시연 신호의 대상자별 조회

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 코드에 미리 작성된 시연 신호를 읽을 뿐, 수신 데이터를 대상자·기기에 연결해 저장하지 않습니다.
- 제한: 기기 ID 연결, 데이터베이스, 입력 검증, 중복 방지, 보존 정책이 없고 `signals`는 `localStorage` 저장 대상도 아닙니다.
