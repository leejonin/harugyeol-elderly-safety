# 움직임 수집

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

움직임 센서에서 실내 활동 감지 기록을 수신하도록 계획된 센서 연동 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 움직임 센서 | 실내 활동 발생 여부를 감지하도록 계획된 외부 장치 |
| 움직임 기록 | 감지 또는 미감지 상태와 관련 시각을 나타내는 생활 신호 |
| 미감지 | 데이터가 수신되지 않은 상태와 구분해야 하는 활동 기록 상태 |

## 3. 개념 설명

기획상 움직임 센서 이벤트를 수신해 대상자의 실내 활동 기록으로 전달해야 합니다. 현재는 수신 통신이나 이벤트 처리 코드가 없고, `js/data.js`에 움직임 감지·미감지 예시가 정적으로 생성됩니다. 미감지와 미수신을 구분하는 문구는 있으나 실제 수신 흐름으로 판별하지 않습니다.

주요 코드 경로:

- 실제 수신 구현 코드: 없음
- `js/data.js`: `motion` 종류의 시연 신호와 움직임 장치 예시
- `js/pages/dashboard.js`: 시연 움직임 상태 표시
- `js/pages/pattern.js`: 시연 움직임 기록 조회
- `js/common.js`: 센서 미연동 상태와 상태 문구 정의

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 움직임 센서 데이터를 수신하지 않습니다.
- 제한: 장치 통신, 수신 이벤트 저장, 감지 공백 계산, 통신 장애 판별 기능이 없습니다.
