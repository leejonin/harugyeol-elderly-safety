# 문 열림 수집

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

문 열림 센서에서 발생한 기록을 수신하도록 계획된 센서 연동 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 문 열림 센서 | 문이 열린 사건을 감지하도록 계획된 외부 장치 |
| 문 열림 기록 | 문 열림 발생 사실과 시각을 나타내는 생활 신호 |
| 상태 해석 제한 | 문 열림 한 건만으로 외출 또는 귀가를 확정하지 않는 원칙 |

## 3. 개념 설명

기획상 문 열림 사건을 수신해 대상자와 센서에 연결해야 합니다. 현재 저장소에는 센서 통신이나 수신 처리 코드가 없고 `js/data.js`에 `kind: "door"`인 예시 한 건만 있습니다. 생활패턴 화면도 이 값을 `문 열림`으로만 표시하며 외출·귀가로 해석하지 않습니다.

주요 코드 경로:

- 실제 수신 구현 코드: 없음
- `js/data.js`: `door` 종류의 시연용 신호와 현관문 장치 예시
- `js/pages/pattern.js`: 문 열림 레이블 및 해석 제한 문구 표시
- `js/common.js`: 센서 미연동 상태 표시

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 문 열림 센서 데이터를 수신하지 않습니다.
- 제한: 장치 연결, 이벤트 수신·검증·중복 처리·저장 기능이 없으며 화면 값은 시연 데이터입니다.
