# 전력 사용 수집

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

스마트 플러그에서 가전 전력 사용 관련 데이터를 수신하도록 계획된 센서 연동 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 스마트 플러그 | 가전의 전력 사용 상태를 제공하도록 계획된 외부 장치 |
| 전력 사용 기록 | 가전 사용 여부와 시각을 나타내는 생활 신호 |
| 시연 신호 | 실제 장치 수신값이 아니라 `js/data.js`에 작성된 `kind: "plug"` 예시 |

## 3. 개념 설명

기획상 스마트 플러그 데이터를 받아 대상자별 생활 기록으로 전달해야 합니다. 현재 저장소에는 스마트 플러그 통신, 수신 API, 장치 인증, 이벤트 변환 또는 수신값 저장 코드가 없습니다. 화면에 보이는 전기포트·TV 기록은 시연 데이터일 뿐입니다.

주요 코드 경로:

- 실제 수신 구현 코드: 없음
- `js/data.js`: `plug` 종류의 시연용 신호와 스마트 플러그 장치 예시
- `js/common.js`: 센서 미연동 태그와 시연 배너
- `js/pages/pattern.js`: 시연 `plug` 기록 표시

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 스마트 플러그로부터 데이터를 수신하지 않습니다.
- 제한: 통신 규격, 수신 엔드포인트, 장치 식별·인증, 오류 처리와 저장 방식이 구현되지 않았습니다.
