# 미감지·미수신 구분

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

활동이 감지되지 않은 상태와 센서 데이터 자체가 도착하지 않은 상태를 서로 다른 문구로 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 움직임 미감지 | 데이터는 수신된 것으로 전제하지만 활동 기록이 없는 상태 |
| 데이터 미수신 | 센서 데이터가 도착하지 않아 활동 여부를 판단할 수 없는 상태 |
| 연결 이상 | 기기 객체의 `connection` 값이 `disconnected`인 상태 |

## 3. 개념 설명

공통 상태 맵은 `motion_none`을 “움직임 미감지(데이터 수신됨)”, `data_not_received`를 “센서 데이터 수신 안 됨”으로 구분합니다. 대시보드는 시연 대상자의 요약 상태를 이 문구로 변환하고, 생활패턴 화면은 기기의 마지막 수신값과 연결 상태에 따라 미수신·연결 이상·수신 정상 배지를 표시합니다.

주요 코드 경로:

- `js/common.js`: 미감지·미수신·연결 이상 상태 문구 정의
- `js/pages/dashboard.js`: 시연 요약 상태를 활동 상태 참고로 변환
- `js/pages/pattern.js`: 기기 수신 상태 분기와 표시
- `js/data.js`: 시연용 요약 상태, 연결 상태, 마지막 수신 시각

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 미감지와 미수신을 서로 다른 문구와 배지로 표시합니다.
- 제한: 실제 센서 통신 결과에서 두 상태를 판별하지 않으며, 대시보드의 `motion_none`은 `check_needed` 상태를 단순 변환한 값입니다.
