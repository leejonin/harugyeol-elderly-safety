# 마지막 수신 시각 확인

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

대상자에게 연결된 센서별 마지막 데이터 수신 시각을 화면에서 확인하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 마지막 수신 시각 | 시연 기기 객체의 `lastReceivedAt` 값 |
| 수신 정상 | 마지막 수신값이 있고 기기 연결 상태가 끊김이 아닌 화면 상태 |
| 데이터 미수신 | `lastReceivedAt` 값이 없는 화면 상태 |

## 3. 개념 설명

생활패턴 화면은 선택 대상자의 기기 중 스피커를 제외한 센서에 대해 수신 상태와 마지막 시각을 표시합니다. 대시보드 기기 상태 영역은 스피커를 포함해 기기별 마지막 수신 시각을 표시합니다. 값은 시연 기기 데이터에서 읽으며 실제 장치 통신으로 갱신되지 않습니다.

주요 코드 경로:

- `js/pages/pattern.js`: 센서별 수신 상태와 마지막 시각 표시
- `js/pages/dashboard.js`: 대상자 기기별 마지막 수신 시각 표시
- `js/data.js`: 시연용 `lastReceivedAt`과 연결 상태
- `js/common.js`: 시각 변환 및 수신·연결 상태 배지

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 기기별 마지막 수신 시각과 화면 상태를 표시합니다.
- 제한: 실제 센서 메시지 수신, 수신 시각 갱신, 서버 시간 기준, 지연·오프라인 판정 로직은 없습니다.
