# 최근 생활 신호 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

선택한 어르신의 최근 가전 사용·문 열림·움직임 기록을 대시보드에 요약 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 생활 신호 | `plug`, `door`, `motion` 종류로 표현되는 시연 기록 |
| 최근 신호 | 현재 코드에서 대상자별 신호 배열의 앞 다섯 항목 |
| 데이터 미수신 | 대상자의 `summaryStatus`가 `data_not_received`인 시연 상태 |

## 3. 개념 설명

대시보드는 전체 시연 신호에서 선택 대상자의 기록을 필터링한 후 앞 다섯 항목의 시각과 설명을 표시합니다. 데이터 미수신 상태이면 기록 대신 상태 배지를 우선 표시합니다. 코드에서 필터 후 별도 최신순 정렬은 하지 않으므로 데이터 배열의 저장 순서를 전제로 합니다.

주요 코드 경로:

- `js/pages/dashboard.js`: 대상자별 신호 필터, 다섯 항목 제한, 목록 표시
- `js/data.js`: 시연용 가전·문 열림·움직임 기록
- `js/common.js`: 시각 형식과 데이터 미수신 배지
- `pattern.html`, `js/pages/pattern.js`: 생활패턴 상세 화면 연결

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 대상자별 생활 신호 최대 다섯 건을 표시합니다.
- 제한: 실제 센서 수신이 없고, 최신순 정렬을 보장하지 않으며, 실시간 갱신도 수행하지 않습니다.
