# 마지막 확인 시각 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

선택 대상자의 최근 안부 확인 시각과 데이터 갱신 시각을 서로 구분해 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 최근 안부 확인 시각 | 대상자 데이터의 `lastCheckAt` 값 |
| 데이터 갱신 시각 | 대상자 데이터의 `lastDataAt` 값 |
| 로컬 표시 시각 | ISO 시각을 브라우저의 한국어 지역 형식으로 변환한 값 |

## 3. 개념 설명

대시보드는 `최근 안부 확인`과 `데이터 갱신`을 한 줄에서 별도 레이블로 표시합니다. 값이 없으면 공통 시각 포맷 함수가 `—`를 표시합니다. 현재 값은 페이지 로드 시 생성되는 시연 시각이며 실제 확인 시스템이나 센서 수신 시스템에서 전달되지 않습니다.

주요 코드 경로:

- `js/pages/dashboard.js`: 두 시각을 구분해 렌더링
- `js/common.js`: `formatDateTime()` 한국어 로컬 시각 변환
- `js/data.js`: 시연용 `lastCheckAt`, `lastDataAt` 생성

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 최근 안부 확인과 데이터 갱신 시각을 구분해 표시합니다.
- 제한: 실제 안부 확인 결과나 센서 수신 이벤트에 따른 시각 갱신 및 서버 시간 동기화는 없습니다.
