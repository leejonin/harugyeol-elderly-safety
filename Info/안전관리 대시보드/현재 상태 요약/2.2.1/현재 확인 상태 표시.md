# 현재 확인 상태 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

선택한 어르신의 이상 변화 및 안부 확인 진행 상태를 대시보드 배지로 요약해 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 요약 상태 | 대상자 데이터의 `summaryStatus` 상태 코드 |
| 상태 배지 | 상태 코드를 한국어 문구와 색상으로 표시하는 UI |
| 진행 중 대응 | 조치 완료 값이 없는 첫 시연 알림의 현재 상태 |

## 3. 개념 설명

대시보드는 선택 대상자의 `summaryStatus`를 공통 상태 맵으로 변환해 표시합니다. 해결되지 않은 알림이 있으면 해당 알림의 진행 상태도 대응 요약에 표시합니다. 상태 코드는 시연 데이터에 미리 들어 있으며 실제 센서나 생활패턴 AI가 갱신하지 않습니다.

주요 코드 경로:

- `js/pages/dashboard.js`: 대상자 요약 상태와 진행 중 대응 표시
- `js/common.js`: 상태 코드별 문구와 배지 스타일 클래스 정의
- `js/data.js`: 시연용 `summaryStatus` 및 알림 상태
- `css/style.css`: 상태 배지 표현

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 현재 상태와 대응 진행 상태를 요약 표시합니다.
- 제한: 실제 이상 변화 분석, 음성 안부 확인, 실시간 상태 동기화는 미구현입니다.
