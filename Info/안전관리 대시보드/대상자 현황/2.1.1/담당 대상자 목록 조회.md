# 담당 대상자 목록 조회

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

로그인한 시연 사용자가 접근할 수 있는 담당 어르신 목록을 대시보드에 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 담당 대상자 | 현재 사용자에게 연결된 것으로 시연 데이터에 정의된 어르신 |
| 접근 가능 대상자 | 시연 사용자 객체의 `elderIds`에 ID가 포함된 어르신 |
| 시연 데이터 | 서버 조회 결과가 아니라 `js/data.js`에서 생성하는 예시 데이터 |

## 3. 개념 설명

대시보드는 시연 세션의 `userId`로 사용자 객체를 찾고, 그 사용자의 `elderIds`에 포함된 어르신만 필터링해 목록으로 표시합니다. 확인 필요 대상자를 먼저 배치한 뒤 이름순으로 정렬합니다.

주요 코드 경로:

- `dashboard.html`: 대상자 목록이 표시되는 대시보드 진입점
- `js/pages/dashboard.js`: 접근 가능한 대상자 조회·정렬·목록 렌더링
- `js/common.js`: `getAccessibleElders()` 접근 범위 필터
- `js/data.js`: 시연 사용자와 대상자 및 연결 ID 정의

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: **시연 데이터 기준**으로 로그인 사용자별 담당 대상자 목록을 표시합니다.
- 제한: 운영 서버·데이터베이스 조회, 실제 담당자 배정 동기화, 실시간 갱신은 없습니다.
