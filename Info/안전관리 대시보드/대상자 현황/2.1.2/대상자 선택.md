# 대상자 선택

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

담당 대상자를 선택하고 해당 어르신의 상태·생활 신호·대응 요약·기기 상태를 표시하는 웹 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 선택 대상자 | 대시보드 URL의 `elder` 쿼리 값으로 지정된 어르신 |
| 접근 범위 | 현재 시연 사용자의 `elderIds`에 포함된 대상자 집합 |
| 기본 선택 | 유효한 `elder` 값이 없을 때 목록의 첫 대상자를 선택하는 동작 |

## 3. 개념 설명

목록 항목을 누르면 `dashboard.html?elder={대상자 ID}`로 이동합니다. 코드는 요청한 ID가 로그인 사용자의 접근 가능 목록에 포함되는지 확인하며, 유효하지 않으면 첫 대상자를 선택합니다. 선택된 대상자의 상태, 최근 신호, 알림, 분석 준비 메모와 기기 상태를 한 화면에 렌더링합니다.

주요 코드 경로:

- `dashboard.html`: 선택 결과를 표시할 `dashboard-root`
- `js/pages/dashboard.js`: 쿼리 검증, 선택 링크 생성, 대상자 상세 렌더링
- `js/common.js`: 쿼리 읽기와 접근 가능 대상자 필터
- `js/data.js`: 선택 화면에 사용하는 시연 데이터

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: **시연 데이터 기준**으로 대상자 선택과 선택 결과 화면 갱신이 동작합니다.
- 제한: 표시 정보는 실제 센서·생활패턴 AI·운영 데이터가 아니며 페이지 이동 방식으로 다시 렌더링합니다.
