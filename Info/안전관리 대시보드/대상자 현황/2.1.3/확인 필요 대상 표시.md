# 확인 필요 대상 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

안부 확인이나 후속 대응이 필요한 것으로 지정된 어르신을 목록에서 구분해 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 확인 필요 대상 | 시연 대상자 데이터의 `needsAttention` 값이 `true`인 어르신 |
| 우선 배치 | 확인 필요 대상을 일반 대상보다 목록 앞에 정렬하는 동작 |
| 확인 필요 표시 | 대상자 이름 옆 문구와 강조선으로 상태를 구분하는 표현 |

## 3. 개념 설명

`js/pages/dashboard.js`는 `needsAttention` 값이 참인 대상자를 목록 앞쪽에 정렬하고 `확인 필요` 문구와 강조 스타일을 적용합니다. 이 값은 현재 `js/data.js`의 시연 데이터에 미리 지정되어 있으며 센서나 AI 결과로 계산되지 않습니다.

주요 코드 경로:

- `js/pages/dashboard.js`: 확인 필요 우선 정렬, 문구 및 클래스 적용
- `js/data.js`: 대상자별 시연용 `needsAttention` 값
- `css/style.css`: 확인 필요 항목의 강조선 스타일
- `dashboard.html`: 목록 표시 화면

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: **시연 데이터 기준**으로 확인 필요 대상을 우선 배치하고 시각적으로 구분합니다.
- 제한: `needsAttention`을 실제 생활 신호나 대응 상태에서 산출·갱신하는 로직과 서버 연동은 없습니다.
