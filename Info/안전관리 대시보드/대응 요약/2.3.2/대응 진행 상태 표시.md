# 대응 진행 상태 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

본인 질문, 보호자 확인, 기관 연결로 이어지는 대응의 현재 진행 상태를 대시보드에서 요약하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 진행 중 대응 | `resolution` 값이 없는 첫 대상자 알림 |
| 알림 상태 | `voice_pending` 등 현재 단계를 나타내는 시연 상태 코드 |
| 보호자 전달 상태 | `requested`, `delivered`, `acknowledged` 중 하나로 표현하는 요청 상태 |

## 3. 개념 설명

대시보드는 선택 대상자의 해결되지 않은 첫 알림을 찾아 상태 배지를 표시합니다. 해당 알림에 보호자 요청 정보가 있으면 전달 상태 문구도 추가합니다. 본인 질문과 기관 연결의 상세 흐름은 대시보드 요약에 모두 펼쳐 표시하지 않고 알림 상세의 시연 이력에서 확인합니다.

주요 코드 경로:

- `js/pages/dashboard.js`: 미완료 알림 선택, 상태 및 보호자 요청 요약
- `js/common.js`: 상태 배지와 전달 상태 문구 정의
- `js/data.js`: 시연용 음성·보호자·기관 요청 상태와 단계 이력
- `js/pages/alerts.js`: 상세 대응 이력 표시

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 해결되지 않은 첫 알림의 상태와 보호자 요청 상태를 표시합니다.
- 제한: 실제 스피커 질문, 보호자 전달, 기관 연결, 서버 상태 동기화가 없으며 여러 진행 건을 종합하지 않습니다.
