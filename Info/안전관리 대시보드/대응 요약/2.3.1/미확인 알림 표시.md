# 미확인 알림 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

선택 대상자의 아직 확인하지 않은 알림을 대시보드 대응 요약 영역에 우선 노출하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 미확인 알림 | 알림 객체의 `read` 값이 `false`인 항목 |
| 우선 표시 | 대응 요약에서 미확인 건수와 개별 알림 카드를 먼저 보여 주는 동작 |
| 확인 처리 | 알림 상세를 열 때 `read` 값을 `true`로 바꾸어 `localStorage`에 저장하는 동작 |

## 3. 개념 설명

대시보드는 선택 대상자의 알림 중 `read`가 거짓인 항목을 필터링하여 건수, 제목, 판단 사유와 상세 링크를 표시합니다. 상세 화면을 열면 읽음 상태가 브라우저 `localStorage`에 저장되어 다음 대시보드 표시에서 제외됩니다.

주요 코드 경로:

- `js/pages/dashboard.js`: 미확인 알림 필터와 카드 표시
- `js/pages/alerts.js`: 상세 진입 시 읽음 처리
- `js/data.js`: 시연 알림과 브라우저 저장 기능
- `css/style.css`: 미확인 알림 강조 스타일

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: **시연 데이터 기준**으로 미확인 알림을 표시하고 상세 열람 시 브라우저에 읽음 상태를 저장합니다.
- 제한: 실제 알림 서버, 여러 사용자 간 읽음 상태 동기화, 외부 알림 수신은 없습니다.
