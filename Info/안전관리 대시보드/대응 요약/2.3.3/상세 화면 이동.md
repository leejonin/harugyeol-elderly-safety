# 상세 화면 이동

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

대시보드에서 선택한 알림의 발생 근거와 대응 내역을 보여 주는 상세 화면으로 이동하는 웹 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 알림 ID | 상세 대상을 식별하는 `alerts.html?id={알림 ID}`의 쿼리 값 |
| 상세 화면 | 판단 근거, 음성 확인, 보호자 요청, 단계별 이력을 표시하는 화면 |
| 접근 검증 | 알림의 대상자가 현재 시연 사용자의 접근 범위에 포함되는지 확인하는 처리 |

## 3. 개념 설명

대시보드의 미확인 알림 제목은 알림 ID를 포함한 상세 URL로 연결됩니다. 상세 화면은 ID와 사용자 접근 범위를 확인한 뒤 발생 시각, 판단 근거, 음성 안부 상태, 보호자 요청 및 단계별 이력을 표시합니다. 잘못된 ID나 접근 범위 밖 알림에는 오류 안내를 표시합니다.

주요 코드 경로:

- `js/pages/dashboard.js`: 알림 상세 링크 생성
- `alerts.html`: 알림 상세 화면 진입점
- `js/pages/alerts.js`: ID 조회, 접근 검증, 상세 내용 표시
- `js/common.js`: 쿼리 읽기와 접근 가능 대상자 ID 조회
- `js/data.js`: 상세 화면의 시연 알림 데이터

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: **시연 데이터 기준**으로 알림 상세 화면 이동과 접근 검증이 동작합니다.
- 제한: 표시되는 발생 근거와 대응 이력은 실제 센서·AI·스피커·외부 알림에서 생성된 정보가 아닙니다.
