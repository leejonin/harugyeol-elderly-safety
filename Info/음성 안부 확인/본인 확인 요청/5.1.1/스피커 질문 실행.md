# 5.1.1 스피커 질문 실행

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

복합 이상 변화가 확인되었을 때 대상 어르신의 실내 스피커로 안부 질문을 전달하는 기능입니다.

## 2. 용어 정의

- 실내 스피커: 어르신 주거 공간에 설치되어 안부 질문을 재생할 외부 장치입니다.
- 브라우저 TTS: 웹 채팅 답변을 사용자 브라우저에서 읽는 기능으로, 실내 스피커와 별개입니다.

## 3. 개념 설명

생활패턴 분석의 확인 필요 판단을 입력으로 받아 스피커 장치에 질문을 요청하고 실행 결과를 받아야 합니다. 현재는 `alert.voice.questionSent`와 `questionAt` 예시 값 및 대응 이력만 있으며 실제 장치 호출 코드는 없습니다. `10.1.2`의 Web Speech API 음성 읽기는 웹 채팅용이므로 이 기능을 구현한 것으로 보지 않습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 알림 상세에서 예시 질문 시각과 `스피커: 시연 미연동` 문구를 표시합니다.
- 제한: 실내 스피커 등록·통신·질문 전송·실행 결과 수신이 모두 미연동입니다.
- 주요 코드 경로: `js/data.js`(예시 음성 상태), `js/pages/alerts.js`(시연 상태 표시), `js/common.js`(스피커 미연동 표시)
- 핵심 연동 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 예시 데이터 표시는 존재하지만 실내 스피커 질문 실행은 미구현이며 브라우저 TTS와 별개라는 현재 동작과 제한을 기록
- 변경 이유: 시연 화면과 실제 장치 연동 상태를 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`, `js/common.js`
