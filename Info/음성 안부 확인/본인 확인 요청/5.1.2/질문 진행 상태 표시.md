# 5.1.2 질문 진행 상태 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

안부 질문의 요청·실행 여부와 질문 시각을 웹 화면에 표시하는 기능입니다.

## 2. 용어 정의

- 질문 진행 상태: 스피커 질문이 실행되었는지와 언제 요청되었는지를 나타내는 정보입니다.
- 예시 데이터: 실제 스피커에서 수신한 값이 아니라 시연을 위해 코드에 작성된 값입니다.

## 3. 개념 설명

알림별 `voice.questionSent`와 `voice.questionAt`을 읽어 질문 미실행 여부 또는 질문 시각을 표시합니다. 현재 화면 렌더링은 동작하지만 값은 `js/data.js`의 예시 데이터이며 실내 스피커의 실제 실행 상태를 반영하지 않습니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 알림 상세에서 질문 시각, 질문 실행 여부 및 음성 확인 진행 상태를 표시합니다.
- 제한: 스피커 요청·실행 결과를 실시간으로 수신하거나 갱신하지 않으며 새 질문을 발생시키는 기능도 없습니다.
- 주요 코드 경로: `js/data.js`(질문 상태 예시), `js/pages/alerts.js`(상태·시각 표시), `js/common.js`(상태 문구)

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 예시 질문 상태의 웹 표시는 구현되었으나 실제 스피커 상태 연동은 미구현이라는 동작과 제한을 기록
- 변경 이유: 표시 기능과 장치 연동 기능의 구현 범위를 명확히 하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`, `js/common.js`

- 기능 ID: `5.1.2`
- 관련 기능 ID: `5.1.1`, `5.2.1`, `5.2.2`, `6.1.3`
