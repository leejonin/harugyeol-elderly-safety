# 5.2.3 확인 결과 기록

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

안부 질문 시각과 응답 결과를 해당 알림에 연결해 기록하는 기능입니다.

## 2. 용어 정의

- 음성 확인 기록: 질문 시각, 질문 실행 여부, 응답 결과 및 응답 시각으로 구성된 정보입니다.
- 알림 연결: 음성 확인 정보를 특정 알림 객체의 `voice` 필드에 포함하는 구조입니다.

## 3. 개념 설명

예시 알림 객체에는 `voice.questionAt`, `questionSent`, `response`, `responseAt` 필드가 있어 알림과 음성 결과의 관계를 표현합니다. 화면은 이 값을 조회하지만 실제 스피커 결과를 받아 새 기록을 만들거나 갱신하는 처리는 없습니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 예시 음성 확인 기록이 알림 객체에 연결되어 상세 화면과 대응 이력에서 조회됩니다.
- 제한: 실제 질문·응답 이벤트 수신, 기록 생성 API, 운영 서버 및 데이터베이스가 없습니다.
- 주요 코드 경로: `js/data.js`(알림별 음성 기록 구조), `js/pages/alerts.js`(기록 조회), `js/data.js`의 `saveStore`(시연 `localStorage`)

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 알림 연결 데이터 구조와 예시 조회는 있으나 실제 결과를 생성·수신해 기록하지 못한다는 동작과 제한을 기록
- 변경 이유: 데이터 표현과 실제 연동 기록 기능을 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`
