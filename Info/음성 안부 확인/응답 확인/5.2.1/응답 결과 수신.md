# 5.2.1 응답 결과 수신

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

실내 스피커의 안부 질문에 대한 어르신의 응답 여부와 확인 결과를 수신하는 기능입니다.

## 2. 용어 정의

- 응답 결과: 안부 질문에 응답했는지와 확인된 상태를 나타내는 장치 연동 결과입니다.
- 브라우저 TTS: AI 채팅 답변을 읽는 출력 기능이며 어르신 음성 응답을 수신하지 않습니다.

## 3. 개념 설명

스피커 또는 음성 처리 시스템에서 응답 결과와 시각을 받아 해당 알림에 연결해야 합니다. 현재 `response`, `responseAt` 예시 필드만 정의되어 있고 외부 음성 입력, 음성 인식, 결과 수신 API는 없습니다. `10.1.2`는 음성 출력만 제공하므로 이 기능과 다릅니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 예시 알림에 저장된 `ok` 또는 `no_response` 값을 알림 상세에서 읽어 표시합니다.
- 제한: 마이크 입력, 음성 인식, 실내 스피커 응답 수신 및 실제 결과 저장이 모두 미연동입니다.
- 주요 코드 경로: `js/data.js`(예시 응답 값), `js/pages/alerts.js`(예시 결과 표시)
- 핵심 연동 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 응답 결과는 예시 데이터로만 표현되며 실제 수신 기능은 없다는 현재 동작과 제한을 기록
- 변경 이유: 예시 응답 표시를 실제 음성 응답 수신으로 오인하지 않도록 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `5.2.1`
- 관련 기능 ID: `5.1.1`, `5.1.2`, `5.2.2`, `5.2.3`, `5.3.1`, `10.1.2`
