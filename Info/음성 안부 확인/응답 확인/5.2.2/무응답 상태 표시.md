# 5.2.2 무응답 상태 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

정해진 안부 확인 절차에서 응답을 받지 못한 상태를 웹 화면에 표시하는 기능입니다.

## 2. 용어 정의

- 무응답: 질문 이후 응답을 받지 못한 상태를 뜻하며 위험 확정을 의미하지 않습니다.
- 음성 안부 확인 진행 중: 무응답 예시 상태에 사용하는 화면용 상태 문구입니다.

## 3. 개념 설명

알림의 `voice.response`가 `no_response`이면 알림 상세에 `무응답`과 음성 안부 확인 진행 중 배지를 표시합니다. 현재 무응답 값은 실제 스피커 수신 결과나 타임아웃 계산이 아니라 시연용 예시 데이터입니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 예시 알림의 무응답 상태와 관련 대응 이력을 화면에 표시합니다.
- 제한: 응답 대기 시간, 타임아웃 기준, 실제 응답 수신 및 자동 상태 전환은 구현되지 않았습니다.
- 주요 코드 경로: `js/data.js`(무응답 예시), `js/pages/alerts.js`(무응답 표시), `js/common.js`(진행 상태 배지)

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 무응답 문구 표시는 구현되었으나 실제 수신·시간 기준 없이 예시 값만 사용한다는 동작과 제한을 기록
- 변경 이유: 화면 상태와 실제 안부 확인 절차를 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`, `js/common.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `5.2.2`
- 관련 기능 ID: `5.2.1`, `5.2.3`, `5.3.1`, `6.1.3`
