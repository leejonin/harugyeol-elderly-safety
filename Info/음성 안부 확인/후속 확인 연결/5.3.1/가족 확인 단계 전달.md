# 5.3.1 가족 확인 단계 전달

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

무응답 또는 이상 신호 지속 시 확인 절차를 가족·보호자 확인 요청 단계로 넘기는 기능입니다.

## 2. 용어 정의

- 후속 확인: 본인 응답을 확인하지 못했을 때 다음 담당자에게 확인을 요청하는 단계입니다.
- 외부 알림: 문자, 앱 푸시, 전화 등 웹 밖의 전달 수단으로 현재 방식은 정해지지 않았습니다.

## 3. 개념 설명

음성 무응답이나 지속 신호를 조건으로 보호자 요청을 생성하고 전달해야 합니다. 현재 예시 알림에는 `guardianRequest`와 단계별 이력이 미리 들어 있지만 조건 평가, 단계 전환 및 외부 전달 로직은 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 가족 확인 요청이 이미 발생한 예시 상태와 시각을 웹에서 표시합니다.
- 제한: 무응답 기반 자동 전환, 보호자 선택, 외부 알림 전송 및 전달 결과 수신이 모두 미연동입니다.
- 주요 코드 경로: `js/data.js`(예시 보호자 요청), `js/pages/alerts.js`(요청 상태 표시), `js/common.js`(외부 알림 미연동 표시)
- 핵심 연동 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 가족 확인 요청 예시는 표시되지만 실제 단계 전환과 외부 전달은 미구현이라는 동작과 제한을 기록
- 변경 이유: 시연 대응 이력을 실제 전달 처리로 오인하지 않도록 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`, `js/common.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `5.3.1`
- 관련 기능 ID: `5.2.2`, `6.2.1`, `6.2.2`, `6.4.1`
