# 문 열림 변화 비교

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

대상자의 평소 문 열림 패턴과 현재 문 열림 기록의 차이를 분석하도록 계획된 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 문 열림 패턴 | 시간대와 빈도 등 누적 문 열림 기록의 반복 경향 |
| 현재 문 열림 기록 | 비교 대상이 되는 최근 문 열림 사건 |
| 해석 제한 | 문 열림 기록만으로 외출 또는 귀가를 확정하지 않는 원칙 |

## 3. 개념 설명

현재 `js/data.js`에는 `door` 종류의 시연 기록이 한 건 있지만, 문 열림에 대한 평소 기준 구간이나 비교 결과는 없습니다. 생활패턴 화면은 사건을 점으로 표시하고 “문 열림”으로만 표기하며, 패턴 차이·빈도·시간대 변화를 계산하지 않습니다.

주요 코드 경로:

- 실제 변화 비교 구현 코드: 없음
- `js/data.js`: 시연용 문 열림 사건
- `js/pages/pattern.js`: 문 열림 사건 표시와 외출·귀가 해석 제한 문구
- `js/common.js`: AI 분석 미연동 상태 표시

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 평소 문 열림 패턴과 현재 기록을 비교하거나 변화 여부를 판정하지 않습니다.
- 제한: 실제 문 센서 수신, 개인별 문 열림 기준, 비교 규칙과 판단 결과가 없습니다.
