# 복합 신호 판단

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 15:46 KST

## 1. 개요

여러 생활 변화가 함께 나타나는지를 종합하여 안부 확인 필요 여부를 판단하도록 계획된 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 복합 신호 | 가전 사용, 문 열림, 움직임 등 둘 이상의 생활 변화 조합 |
| 안부 확인 필요 | 추가 확인 절차를 시작해야 한다는 판단 상태 |
| 판단 근거 | 판단에 사용된 개별 생활 변화 설명 |

## 3. 개념 설명

시연 데이터에는 “복합 생활 변화 — 안부 확인 필요” 알림과 전기포트 미사용·움직임 미감지 사유가 미리 작성되어 있습니다. 대상자의 `summaryStatus`와 `needsAttention`도 고정 시연값입니다. 코드가 여러 신호를 시간적으로 결합하거나 점수·규칙·AI 모델로 판단해 알림을 생성하지 않습니다.

주요 코드 경로:

- 실제 복합 판단 구현 코드: 없음
- `js/data.js`: 사전 작성된 복합 알림, 판단 사유, 대상자 상태
- `js/pages/dashboard.js`: 시연 판단 상태와 사유 표시
- `js/pages/pattern.js`: 시연 알림 사유 표시
- `js/common.js`: AI 분석 미연동 상태 표시

## 4. 현재 구현 상태

- 상태: **구현 중** (CSV 규칙 시연 경로)
- 실제 동작: 합성 CSV에서 4.2.1~4.2.3 결과를 규칙으로 종합해 `check_needed` 등 시연 판단과 `reasons` 목록을 `pattern.html`·`dataset.html`에 표시합니다.
- 제한: `js/data.js` 알림 자동 생성(6.1.1)·대시보드 상태 갱신 없음. 클라우드 ML·실제 센서 연동 아님. `data.js` 고정 알림 근거와 CSV 규칙 근거는 별개입니다.
- 주요 코드 경로: `js/pattern-analysis.js`, `js/pages/pattern-analysis-ui.js`
