# 가전 사용 변화 비교

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

대상자의 평소 가전 사용 시간대와 현재 사용 기록의 차이를 분석하도록 계획된 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 평소 사용 시간대 | 대상자의 가전 사용 기준으로 학습되어야 하는 시간 구간 |
| 현재 사용 기록 | 스마트 플러그에서 수신되어야 하는 최근 전력 사용 사건 |
| 변화 비교 | 기준과 현재값의 차이를 계산하고 의미 있는 변화인지 판정하는 처리 |

## 3. 개념 설명

현재 시연 데이터에는 아침 전기포트 기준 구간, “전기포트 사용 없음” 신호 문구, 같은 내용의 알림 사유가 미리 작성되어 있습니다. 코드가 스마트 플러그 기록을 집계하거나 기준과 비교해 이 문구·사유를 생성하지는 않습니다.

주요 코드 경로:

- 실제 변화 비교 구현 코드: 없음
- `js/data.js`: 시연용 전기포트 기준 구간, 신호 설명, 알림 사유
- `js/pages/pattern.js`: 기준 구간과 시연 신호 점 표시
- `js/pages/dashboard.js`: 사전 작성된 신호와 알림 사유 표시

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 가전 사용 변화를 계산하거나 판정하지 않습니다.
- 제한: 실제 전력 데이터, 기준 학습, 시간대 비교, 결측·오류 처리, 변화 임계값이 없습니다. 보이는 결과는 시연 데이터입니다.
