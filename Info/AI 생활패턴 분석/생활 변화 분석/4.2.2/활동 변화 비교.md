# 활동 변화 비교

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

평소 움직임과 현재 활동 기록의 차이 및 장시간 미감지를 분석하도록 계획된 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 활동 변화 | 평소 움직임 시간대·빈도와 현재 감지 기록 사이의 차이 |
| 장시간 미감지 | 정해질 기준 시간 동안 움직임 기록이 없는 상태 |
| 데이터 미수신 | 센서 통신이 없어 활동 여부 자체를 판단할 수 없는 상태 |

## 3. 개념 설명

시연 데이터에는 오전 활동 기준 구간, “거실 움직임 미감지” 신호와 알림 사유가 직접 작성되어 있습니다. 화면은 미감지와 미수신 문구를 구분하지만, 코드에는 감지 간격을 계산하거나 평소 기록과 비교해 장시간 미감지를 판정하는 분석이 없습니다.

주요 코드 경로:

- 실제 활동 비교 구현 코드: 없음
- `js/data.js`: 시연용 움직임 기준·신호·알림 사유
- `js/pages/pattern.js`: 시연 기준 구간과 움직임 기록 표시
- `js/pages/dashboard.js`: 시연 활동 상태와 최근 신호 표시
- `js/common.js`: 미감지와 미수신 상태 문구

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 활동 변화나 장시간 미감지를 계산·판정하지 않습니다.
- 제한: 실제 움직임 수신, 비교 기준, 시간 임계값, 통신 장애 분리 판정이 없으며 값은 시연 데이터입니다.
