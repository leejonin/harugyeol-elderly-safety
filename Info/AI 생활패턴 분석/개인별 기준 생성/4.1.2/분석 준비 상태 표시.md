# 분석 준비 상태 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

대상자별로 생활패턴 비교가 가능한지 또는 학습 데이터가 부족한지를 화면에 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 분석 준비 상태 | 시연 기준 객체의 `analysisReady` 값 |
| 준비 완료 | `ready`로 미리 지정된 시연 상태 |
| 데이터 부족 | `insufficient`로 지정되어 개인별 비교가 어렵다고 표시하는 시연 상태 |

## 3. 개념 설명

대시보드는 선택 대상자의 기준 객체가 있으면 설명 메모를 표시하고, `analysisReady`가 `insufficient`일 때 데이터 부족 배지를 추가합니다. 생활패턴 화면도 같은 부족 상태를 비교 영역에 표시합니다. 상태는 실제 학습 데이터량을 계산한 결과가 아니라 시연 데이터의 고정 값입니다.

주요 코드 경로:

- `js/data.js`: 시연용 `analysisReady`와 설명 메모
- `js/pages/dashboard.js`: 분석 준비 메모와 데이터 부족 배지
- `js/pages/pattern.js`: 비교 영역의 데이터 부족 배지
- `js/common.js`: `insufficient_data` 상태 문구

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 비교 가능 여부와 데이터 부족 상태를 화면에 표시합니다.
- 제한: 학습 데이터량, 품질 또는 기간을 실제로 평가해 상태를 산출하지 않으며 학습 엔진도 없습니다.
