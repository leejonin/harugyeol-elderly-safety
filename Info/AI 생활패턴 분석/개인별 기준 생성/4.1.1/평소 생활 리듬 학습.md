# 평소 생활 리듬 학습

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

대상자별 가전 사용·문 열림·움직임 기록에서 평소 생활 리듬을 학습하도록 계획된 AI 분석 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 생활 리듬 | 시간대별 가전 사용, 문 열림, 움직임의 반복 경향 |
| 개인별 기준 | 한 대상자의 현재 기록을 비교하기 위한 평소 패턴 |
| 기준 구간 | 시연 데이터의 `usualWindows`에 미리 작성된 시작·종료 시간대 |

## 3. 개념 설명

기획상 누적 생활 신호를 학습하여 대상자별 비교 기준을 생성해야 합니다. 현재 `js/data.js`의 `baselines`와 `usualWindows`는 코드에 직접 작성된 시연값이며, 기록을 집계하거나 학습해 생성되지 않습니다. 학습 모델, 학습 기간, 최소 데이터량, 재학습 과정도 없습니다.

주요 코드 경로:

- 실제 학습 구현 코드: 없음
- `js/data.js`: 사전 정의된 시연용 `baselines`와 `usualWindows`
- `js/pages/pattern.js`: 시연 기준 구간 시각화
- `js/common.js`: AI 분석 미연동 상태 표시

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 평소 생활 리듬을 학습하거나 기준을 생성하지 않습니다.
- 제한: AI 모델, 통계 학습, 데이터 전처리, 기준 갱신·버전 관리, 학습 품질 검증이 없습니다.
