# 판단 근거 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

어떤 생활 변화가 확인 요청으로 이어졌는지를 화면에 근거 목록으로 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 판단 근거 | 알림 객체의 `reasons` 배열에 들어 있는 생활 변화 설명 |
| 알림 연계 | 생활패턴 화면의 근거에서 해당 알림 상세로 이동하는 연결 |
| 시연 근거 | 실제 분석 결과가 아니라 `js/data.js`에 미리 작성된 사유 |

## 3. 개념 설명

생활패턴 화면은 선택 대상자의 알림별 제목과 `reasons` 항목을 표시하고 상세 링크를 제공합니다. 대시보드 미확인 알림과 알림 상세 화면도 같은 근거 배열을 표시합니다. 근거는 실제 센서·생활패턴 AI가 생성한 것이 아니라 시연 데이터에 직접 작성되어 있습니다.

주요 코드 경로:

- `js/pages/pattern.js`: 알림 연계 판단 근거와 상세 링크 표시
- `js/pages/dashboard.js`: 미확인 알림의 근거 표시
- `js/pages/alerts.js`: 알림 상세의 판단 근거 표시
- `js/data.js`: 시연용 `alerts[].reasons`

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 판단 근거 목록을 여러 화면에 표시하고 알림 상세로 연결합니다.
- 제한: 근거를 생성·검증하는 생활패턴 AI와 실제 센서 연동은 없으며 신뢰도·판정 규칙도 표시하지 않습니다.
