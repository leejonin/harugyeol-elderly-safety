# 평소·현재 비교 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

대상자의 평소 패턴 시간대와 현재 생활 신호 기록을 한 타임라인에서 함께 표시하는 기능입니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 평소 패턴 영역 | 시연 기준의 `usualWindows`를 녹색 구간으로 표현한 영역 |
| 현재 기록 점 | 시연 신호의 발생 시각을 종류별 색상의 점으로 표현한 표시 |
| 24시간 타임라인 | 0시부터 24시까지 기준 구간과 기록을 배치하는 SVG |

## 3. 개념 설명

생활패턴 화면은 `usualWindows`의 시작·종료 시각을 녹색 사각형으로, 대상자의 시연 신호를 발생 시각 위치의 점으로 그립니다. 분석 준비 상태가 데이터 부족이면 배지를 표시합니다. 화면은 두 데이터 집합을 겹쳐 보여 줄 뿐 차이값이나 이상 정도를 계산하지 않습니다.

주요 코드 경로:

- `pattern.html`: 비교 화면 진입점
- `js/pages/pattern.js`: `buildTimelineSvg()` 기준 구간·현재 기록 시각화
- `js/data.js`: 시연용 기준 구간과 생활 신호
- `css/style.css`: SVG 스크롤과 화면 스타일

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: **시연 데이터 기준**으로 평소 구간과 현재 기록을 24시간 SVG에 함께 표시합니다.
- 제한: 실제 학습·센서 데이터가 아니며 차이 계산, 이상도, 날짜 선택이 없습니다. 종류 필터를 적용해도 기준 구간 자체는 종류별로 필터링하지 않습니다.
