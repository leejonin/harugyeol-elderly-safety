## 1. 개요

하루결 프로젝트의 기능 ID, 책임 범위, 구현 상태, 코드 경로와 기능 문서 경로를 통합 관리합니다. 기존 `1.1.1`~`9.2.2` 번호를 유지하고, 이후 구현된 AI 대화·브라우저 음성 읽기·GitHub Pages 배포에는 `10.x`를 부여했습니다.

## 2. 용어 정의

| 용어 | 의미 |
| --- | --- |
| 구현 완료 | 정의된 웹 또는 연동 범위가 현재 코드에서 동작하는 상태 |
| 구현 중 | 화면이나 시연 데이터는 있으나 정의된 전체 범위 또는 실제 연동이 완료되지 않은 상태 |
| 미구현 | 계획만 있고 실제 실행 코드가 없는 상태 |
| 시연 | 예시 데이터나 `localStorage`를 사용하며 운영 센서·서버·DB와 연결되지 않은 상태 |
| 문서 경로 | 해당 기능 ID의 상세 설명 문서 위치 |

## 3. 개념 설명

ID는 기능명이나 폴더가 바뀌어도 유지합니다. 센서·생활패턴 AI·실내 스피커·외부 알림의 예시 화면은 실제 연동 완료로 보지 않습니다. 코드 경로가 `미구현`인 기능은 문서와 분류만 존재합니다.
