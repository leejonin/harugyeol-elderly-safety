# 9.1.3 감지 상태·알림 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

수신된 화재·가스 감지 신호와 관련 알림을 웹 화면에 표시하는 추가 기능 후보입니다.

## 2. 용어 정의

- 감지 상태: 화재 또는 가스 센서가 전달한 정상·감지·장애 등의 상태입니다.
- 감지 알림: 센서 감지 사실과 발생 시각을 사용자에게 보여주는 정보입니다.

## 3. 개념 설명

화재·가스 신호 수신 결과를 상태 코드와 알림 데이터로 변환하고 대상자별 화면에 표시해야 합니다. 현재 공통 상태 코드, 시드 데이터, 대시보드 및 알림 화면 어디에도 화재·가스 항목이 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 서비스 소개 화면에 화재·가스 센서 연동이 추가 기능 후보로만 표시됩니다.
- 제한: 센서 신호 수신, 감지 상태 정의, 알림 생성·표시 및 후속 대응 절차가 없습니다.
- 관련 표시 경로: `index.html`
- 핵심 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 화재·가스 감지 상태와 알림 UI가 모두 미구현이며 후보 안내만 존재한다는 상태를 기록
- 변경 이유: 일반 생활패턴 알림과 미구현 재난 감지 알림을 구분하기 위해 최초 문서화
