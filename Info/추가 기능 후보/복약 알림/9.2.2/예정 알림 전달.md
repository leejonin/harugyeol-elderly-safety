# 9.2.2 예정 알림 전달

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

설정된 복약 일정에 맞춰 대상 사용자에게 복약 안내를 전달하는 추가 기능 후보입니다.

## 2. 용어 정의

- 예정 알림: 저장된 일정의 시각이 되었을 때 발생시키는 복약 안내입니다.
- 전달 수단: 브라우저 알림, 앱 푸시, 문자 또는 스피커 등 향후 정해야 할 채널입니다.

## 3. 개념 설명

복약 일정을 조회하는 스케줄러, 시간대 처리, 전달 대상·수단, 재시도와 결과 기록이 필요합니다. 현재 일정 설정과 외부 알림 연동이 모두 없어 예정 알림을 발생시키지 않습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 서비스 소개 화면에서 복약 알림이 추가 기능 후보로만 표시됩니다.
- 제한: 스케줄러, 전달 채널, 브라우저·스피커 알림, 성공·실패 기록 및 재시도 기능이 없습니다.
- 관련 표시 경로: `index.html`
- 핵심 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 복약 예정 알림 전달은 구현되지 않았고 전달 수단도 미정이라는 상태를 기록
- 변경 이유: 후보 안내를 실제 예약 알림 기능으로 오인하지 않도록 최초 문서화
- 관련 파일: `index.html`, `Info/분류.md`
