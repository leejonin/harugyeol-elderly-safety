# 9.2.1 복약 일정 설정

- 문서 초기 생성 일시: 2026-10-15 12:04 KST

## 1. 개요

복약 알림 시각과 사용자에게 표시할 내용을 설정하는 추가 기능 후보입니다.

## 2. 용어 정의

- 복약 일정: 알림을 발생시킬 날짜·시각과 안내 내용의 설정입니다.
- 추가 기능 후보: 핵심 구현 범위로 확정되지 않은 기획 항목입니다.

## 3. 개념 설명

대상자별 일정 입력, 반복 규칙, 안내 내용, 저장과 수정·삭제 기능이 필요합니다. 의료 처방이나 복용량 판단 기능은 이 항목에 포함되지 않으며 현재 일정 데이터 구조와 설정 화면이 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 서비스 소개 화면에서 복약 알림이 추가 기능 후보로만 표시됩니다.
- 제한: 일정 입력 UI, 유효성 검사, 대상자 연결, 저장, 수정 및 삭제 기능이 없습니다.
- 관련 표시 경로: `index.html`
- 핵심 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 복약 일정 설정은 후보 안내만 있고 기능 코드와 데이터 구조가 없다는 상태를 기록
- 변경 이유: 추가 기능 후보의 현재 구현 여부와 범위를 명확히 하기 위해 최초 문서화
- 관련 파일: `index.html`, `Info/분류.md`
