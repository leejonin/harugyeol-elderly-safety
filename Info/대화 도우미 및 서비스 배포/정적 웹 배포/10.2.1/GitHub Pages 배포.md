# 10.2.1 GitHub Pages 배포

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

`main` 브랜치 변경 시 정적 웹 파일을 GitHub Pages에 자동 배포하는 기능입니다.

## 2. 용어 정의

- GitHub Pages: 저장소의 정적 파일을 웹사이트로 제공하는 GitHub 호스팅 기능입니다.
- GitHub Actions 워크플로: 저장소 이벤트에 따라 체크아웃, 아티팩트 업로드와 배포 단계를 자동 실행하는 설정입니다.
- `.nojekyll`: GitHub Pages에서 Jekyll 처리를 사용하지 않도록 하는 빈 파일입니다.

## 3. 개념 설명

워크플로는 `main` 브랜치 푸시 또는 수동 실행으로 시작합니다. 저장소 전체를 Pages 아티팩트로 업로드한 뒤 공식 `deploy-pages` 액션으로 `github-pages` 환경에 배포합니다. 별도 빌드 단계 없이 현재 HTML·CSS·JavaScript 정적 파일을 그대로 배포합니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: GitHub Actions 워크플로 기반 자동 배포와 수동 실행 구성이 저장소에 존재합니다.
- 제한: 정적 호스팅만 제공하므로 서버 API·데이터베이스·센서·실내 스피커·외부 알림 연동을 제공하지 않습니다. 배포 성공 여부는 저장소의 Pages 설정과 Actions 실행 결과에도 의존합니다.
- 주요 코드 경로: `.github/workflows/pages.yml`, `.nojekyll`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: `main` 변경 시 워크플로가 정적 파일을 GitHub Pages에 자동 배포하는 구성과 정적 호스팅 제한을 기록
- 변경 이유: 배포 방식이 수동 파일 업로드가 아닌 워크플로 기반 자동 배포임을 최초 문서화
- 관련 파일: `.github/workflows/pages.yml`, `.nojekyll`
