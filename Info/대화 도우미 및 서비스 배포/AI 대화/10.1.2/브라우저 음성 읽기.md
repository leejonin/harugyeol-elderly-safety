# 10.1.2 브라우저 음성 읽기

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

Web Speech API를 사용해 AI 채팅 답변을 브라우저의 기본 한국어 음성으로 자동 또는 수동 재생하고 중지하는 기능입니다.

## 2. 용어 정의

- Web Speech API: 브라우저가 제공하는 `speechSynthesis`와 `SpeechSynthesisUtterance` 음성 합성 기능입니다.
- 자동 읽기: AI 답변 생성 후 설정이 켜져 있으면 즉시 음성으로 읽는 동작입니다.
- 실내 스피커 연동: 주거 공간의 외부 스피커 장치에 질문을 보내는 별도 기능으로 현재 미구현입니다.

## 3. 개념 설명

브라우저 지원 여부를 확인한 뒤 한국어 음성을 우선 선택해 답변을 읽습니다. 자동 읽기 설정, 답변별 수동 읽기, 현재 음성 중지 및 페이지 이탈 시 중지가 구현되어 있습니다. 이 기능은 웹 채팅 답변 출력용이며 `5.1.1`의 실내 스피커 질문 실행이나 `5.2.1`의 어르신 음성 응답 수신을 구현하지 않습니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 지원 브라우저에서 AI 답변 자동·수동 읽기, 한국어 음성 우선 선택, 읽기 중지와 설정 저장이 동작합니다.
- 제한: 브라우저·운영체제가 제공하는 음성과 Web Speech API 지원 여부에 의존하며 외부 실내 스피커나 마이크 입력과 연결되지 않습니다.
- 주요 코드 경로: `chat.html`, `js/pages/chat.js`, `css/style.css`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 브라우저 TTS의 자동·수동 읽기와 중지 동작, 지원 범위 및 실내 스피커·응답 수신과의 구분을 기록
- 변경 이유: 브라우저 음성 출력과 음성 안부 장치 연동을 명확히 분리하기 위해 최초 문서화
- 관련 파일: `chat.html`, `js/pages/chat.js`, `css/style.css`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `10.1.2`
- 관련 기능 ID: `5.1.1`, `5.2.1`, `7.3.2`, `10.1.1`
