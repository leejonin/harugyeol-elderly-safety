## 개요

하루결 서비스의 기획 기능과 현재 시연 웹의 실제 구현 상태를 동일한 기능 ID로 관리합니다. 웹 표시와 센서·AI·스피커·외부 알림 연동을 구분하며, 각 ID의 상세 상태는 기능 문서와 `기능_ID_목록.md`에서 확인합니다.

## 1. 용어 정의 및 분류 기준

- **대분류:** 서비스의 주요 업무 영역입니다.
- **중분류:** 같은 목적을 가진 기능 묶음입니다.
- **소분류:** 실제로 구현하거나 화면에서 확인할 수 있는 개별 기능입니다.
- **웹:** 웹페이지에서 표시하거나 사용자가 조작하는 기능입니다.
- **연동:** 센서·AI 분석 서버·스피커·알림 전달 수단과 연결해야 실제로 작동하는 기능입니다.

소분류는 기능 단위이며, 스크립트명이나 클래스명은 아직 정하지 않습니다. 대분류별 중분류와 중분류별 소분류의 개수는 필요한 기능에 따라 다르게 구성합니다.

## 6. 표시 원칙

- 이상 신호가 없다는 이유만으로 안전이 확정된 것처럼 표시하지 않습니다.
- 센서 미수신과 움직임 미감지를 구분합니다.
- 알림에 판단 근거와 발생 시각을 함께 표시합니다.
- 개인별 비교에 필요한 데이터가 부족하면 해당 상태를 표시합니다.
- 시연 데이터와 실제 운영 데이터를 구분합니다.
- 구현되지 않은 연동을 완료된 것처럼 표시하지 않습니다.
