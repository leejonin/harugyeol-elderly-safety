# 6.1.3 알림 상세 조회

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

선택한 알림의 발생 시각, 판단 근거, 음성 확인 결과와 대응 내역을 조회하는 기능입니다.

## 2. 용어 정의

- 알림 상세: 하나의 알림에 연결된 원인과 대응 정보를 모아 보여주는 화면입니다.
- 읽음 처리: 상세 화면을 열 때 시연 알림의 `read` 값을 `true`로 저장하는 처리입니다.

## 3. 개념 설명

URL의 알림 ID로 알림을 찾고 로그인 사용자의 대상자 접근 범위를 검사합니다. 허용된 알림이면 근거, 음성 상태, 보호자 요청, 단계별 이력 및 조치 완료 정보를 표시하고 처음 열 때 읽음 상태를 `localStorage`에 저장합니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 시연 알림 상세 조회, 접근 범위 확인, 읽음 처리와 관련 정보 표시가 동작합니다.
- 제한: 표시 데이터는 예시 및 브라우저 저장 값이며 실제 센서·스피커·외부 알림 연동 결과가 아닙니다.
- 주요 코드 경로: `alerts.html`, `js/pages/alerts.js`, `js/data.js`, `js/common.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 상세 화면의 실제 시연 동작과 운영 데이터 연동 부재를 함께 기록
- 변경 이유: 구현된 웹 조회와 미구현 외부 연동을 구분하기 위해 최초 문서화
- 관련 파일: `alerts.html`, `js/pages/alerts.js`, `js/data.js`, `js/common.js`
