# 6.1.2 알림 목록 조회

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

로그인 사용자가 접근 가능한 대상자의 알림을 발생 시각 역순으로 조회하는 기능입니다.

## 2. 용어 정의

- 미확인 알림: `read` 값이 `false`인 시연 알림입니다.
- 접근 가능한 대상자: 시연 사용자 데이터의 `elderIds`에 포함된 어르신입니다.

## 3. 개념 설명

현재 세션의 사용자 ID로 접근 가능한 대상자 ID를 구한 뒤 해당 대상자의 알림만 필터링하고 최신순으로 정렬합니다. 목록에는 제목, 대상자, 발생 시각, 상태와 미확인 강조가 표시됩니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 예시 및 `localStorage` 알림을 대상자 접근 범위에 따라 필터링하여 목록으로 표시합니다.
- 제한: 운영 서버·데이터베이스 조회, 페이지 나누기, 실시간 갱신 및 실제 생성 알림은 없습니다.
- 주요 코드 경로: `alerts.html`, `js/pages/alerts.js`, `js/data.js`, `js/common.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 브라우저 시연 데이터의 목록 조회는 동작하지만 서버 기반 운영 조회는 없다는 동작과 제한을 기록
- 변경 이유: 현재 조회 범위와 데이터 출처를 명확히 하기 위해 최초 문서화
- 관련 파일: `alerts.html`, `js/pages/alerts.js`, `js/data.js`, `js/common.js`
