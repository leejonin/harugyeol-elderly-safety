# 6.1.1 이상 변화 알림 생성

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

생활패턴 분석에서 확인 필요 판단이 발생했을 때 근거와 시각을 포함한 알림을 생성하는 기능입니다.

## 2. 용어 정의

- 이상 변화 알림: 평소와 다른 복합 생활 신호를 근거로 추가 확인이 필요함을 나타내는 기록입니다.
- 판단 근거: 알림 생성에 사용된 가전 사용·움직임 등의 변화 설명입니다.

## 3. 개념 설명

분석 결과를 받아 알림 ID, 대상자, 발생 시각, 제목, 근거, 확인 상태 및 대응 상태를 생성해야 합니다. 현재 알림 객체는 `createSeedData`에 고정되어 있고 분석 엔진이나 신규 알림 생성 처리는 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 미리 작성된 예시 알림이 목록·대시보드·상세 화면에 표시됩니다.
- 제한: 센서와 생활패턴 AI가 미연동이며 판단 결과를 받아 알림을 자동 생성하는 코드가 없습니다.
- 주요 코드 경로: `js/data.js`(고정 예시 알림), `js/pages/dashboard.js`, `js/pages/alerts.js`
- 핵심 생성 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 예시 알림 조회는 가능하지만 이상 변화 판단에 따른 알림 생성은 미구현이라는 동작과 제한을 기록
- 변경 이유: 정적 시드 데이터와 실제 알림 생성 기능을 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/dashboard.js`, `js/pages/alerts.js`

- 관련 기능 ID: `4.2.4`, `4.3.2`, `5.1.1`, `6.1.2`, `6.1.3`
