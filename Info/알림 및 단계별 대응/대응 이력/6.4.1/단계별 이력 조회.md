# 6.4.1 단계별 이력 조회

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

이상 변화 발생부터 본인·보호자·기관 확인까지의 대응 과정을 시간순으로 조회하는 기능입니다.

## 2. 용어 정의

- 대응 이력: 각 대응 단계의 시각, 단계명과 상세 설명을 저장한 기록입니다.
- 타임라인: 대응 이력을 발생 순서에 따라 나열한 화면 표현입니다.

## 3. 개념 설명

알림의 `steps` 배열을 순서대로 읽어 시각, 단계명 및 상세 설명을 표시합니다. 현재 단계 항목은 시드 데이터에 미리 작성되어 있으며 실제 연동 이벤트가 발생할 때 자동으로 추가되지는 않습니다.

## 4. 현재 구현 상태

- 상태: **구현 완료**
- 실제 동작: 예시 알림에 저장된 단계별 대응 이력을 상세 화면에서 시간 정보와 함께 조회합니다.
- 제한: 센서 판단, 스피커, 보호자 및 기관 연동 이벤트로 이력을 자동 생성·검증하는 기능은 없습니다.
- 주요 코드 경로: `js/data.js`(예시 `steps`), `js/pages/alerts.js`(타임라인 표시)

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 저장된 예시 이력 조회는 가능하지만 실제 이벤트 기반 이력 생성은 미구현이라는 동작과 제한을 기록
- 변경 이유: 타임라인 표시와 운영 이력 수집 범위를 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`
