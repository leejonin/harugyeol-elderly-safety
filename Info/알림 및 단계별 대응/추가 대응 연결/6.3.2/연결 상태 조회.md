# 6.3.2 연결 상태 조회

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

보호자·기관 연결 요청의 대상, 요청 시각 및 실제 확인된 진행 상태를 조회하는 기능입니다.

## 2. 용어 정의

- 연결 상태: 요청 생성, 전달, 상대 확인 등 외부 연결의 진행 단계를 나타내는 정보입니다.
- 실제 확인: 외부 수단에서 성공 또는 열람 결과를 받아 검증된 상태입니다.

## 3. 개념 설명

연결 요청 데이터와 외부 전달 결과를 조회해 대상·시각·상태를 표시해야 합니다. 현재 상태 코드 문구 일부와 `agencyRequest` 자리만 있으나 유효한 예시 요청, 상태 렌더링 및 외부 조회 처리가 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 알림에 `agencyRequest`가 있을 때 관리기관 연결 제목을 표시하는 조건 분기만 있으며 현재 시드 데이터는 모두 `null`입니다.
- 제한: 요청 대상·시각·진행 상태를 표시하거나 외부 확인 결과를 조회하지 않습니다.
- 주요 코드 경로: `js/data.js`(빈 기관 요청 필드), `js/pages/alerts.js`(제한적 조건 분기), `js/common.js`(미사용 상태 문구)
- 핵심 조회 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 데이터 자리와 문구는 일부 존재하지만 연결 상태 조회 기능은 동작하지 않는다는 현재 상태를 기록
- 변경 이유: 준비된 데이터 필드를 구현 완료로 오인하지 않도록 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`, `js/common.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `6.3.2`
- 관련 기능 ID: `6.3.1`, `6.4.1`
