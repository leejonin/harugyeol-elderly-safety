# 6.3.1 보호자·기관 연결 요청

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

위험이 커질 때 등록된 보호자 또는 관리기관에 추가 대응 연결을 요청하는 기능입니다.

## 2. 용어 정의

- 추가 대응 연결: 본인·가족 확인 이후 필요한 경우 보호자나 기관에 후속 조치를 요청하는 단계입니다.
- 관리기관: 대상 어르신에게 연결된 복지센터·요양시설 등의 예시 연락 대상입니다.

## 3. 개념 설명

상황과 기존 대응 결과를 기준으로 요청 대상을 선택하고 외부 채널에 연결 요청을 전송해야 합니다. 현재 기관 연락처 예시와 `agencyRequest` 필드는 있으나 모든 예시 알림의 기관 요청은 `null`이며 전송 로직이 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 설정 화면에서 예시 관리기관 연락처를 조회·일부 수정할 수 있습니다.
- 제한: 위험 단계 판단, 요청 생성, 대상 선택, 외부 채널 전송 및 자동 긴급 신고는 구현되지 않았습니다.
- 주요 코드 경로: `js/data.js`(예시 기관·빈 요청 필드), `js/pages/settings.js`(기관 정보 시연), `js/pages/alerts.js`
- 핵심 연결 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 기관 정보 예시는 있으나 실제 보호자·기관 연결 요청은 미구현이라는 동작과 제한을 기록
- 변경 이유: 연락처 관리와 외부 연결 요청을 별도 기능으로 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/settings.js`, `js/pages/alerts.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `6.3.1`
- 관련 기능 ID: `6.2.2`, `6.3.2`, `7.2.2`, `7.2.3`
