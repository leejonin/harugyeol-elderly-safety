# 6.2.1 확인 요청 전달

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

등록된 가족·보호자에게 대상 어르신의 확인 요청을 외부 수단으로 전달하는 기능입니다.

## 2. 용어 정의

- 확인 요청: 보호자가 어르신의 상황을 확인하도록 전달하는 메시지 또는 호출입니다.
- 외부 전달 수단: 문자, 앱 푸시, 전화 등 웹 외부 채널로 현재 방식은 정해지지 않았습니다.

## 3. 개념 설명

보호자 연락 정보를 조회하고 요청을 전송한 뒤 전송 시각과 성공 여부를 기록해야 합니다. 현재 `guardianRequest.state`와 `requestedAt` 예시 값만 있으며 외부 전송 서비스 호출은 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 이미 요청된 것으로 작성된 예시 상태를 알림 상세와 대시보드에서 표시합니다.
- 제한: 외부 알림 수단, 전송 API, 실패 처리 및 실제 전달 결과 수신이 모두 미연동입니다.
- 주요 코드 경로: `js/data.js`(예시 요청), `js/pages/alerts.js`, `js/pages/dashboard.js`, `js/common.js`(외부 알림 미연동 표시)
- 핵심 전달 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 보호자 요청 예시는 표시되지만 실제 외부 확인 요청 전달은 미구현이라는 동작과 제한을 기록
- 변경 이유: 요청 상태 시연과 외부 전달 성공을 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/alerts.js`, `js/pages/dashboard.js`, `js/common.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `6.2.1`
- 관련 기능 ID: `5.3.1`, `6.2.2`, `7.2.1`, `7.2.3`
