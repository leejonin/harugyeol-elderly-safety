# 6.2.2 요청 수신·확인 상태 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

가족·보호자 확인 요청의 전달 상태와 보호자 확인 상태를 구분해 표시하는 기능입니다.

## 2. 용어 정의

- 요청함: 요청이 생성된 것으로 표시하는 시연 상태입니다.
- 전달됨: 외부 채널 전송 성공을 의미하도록 준비된 상태 문구입니다.
- 확인함: 보호자가 요청을 확인한 것으로 표시하는 상태입니다.

## 3. 개념 설명

`requested`, `delivered`, `acknowledged` 상태를 화면 문구로 변환합니다. 현재 예시 요청은 `requested`로 시작하며 보호자 확인 메모를 저장하면 브라우저에서 `acknowledged`로 바뀝니다. 실제 전달 서비스의 수신 확인 값은 사용하지 않습니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 요청 상태와 시각을 표시하고 시연 메모 입력 시 확인 상태로 변경해 `localStorage`에 저장합니다.
- 제한: 외부 전달 성공 및 실제 보호자 열람 여부를 수신하지 않으므로 화면 상태는 운영 증빙이 아닙니다.
- 주요 코드 경로: `js/common.js`(전달 상태 문구), `js/data.js`(예시 상태·저장), `js/pages/alerts.js`, `js/pages/dashboard.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 시연 상태 구분은 동작하지만 외부 채널의 전달·확인 결과와 연동되지 않는다는 동작과 제한을 기록
- 변경 이유: 화면 상태의 의미와 실제 수신 여부를 명확히 하기 위해 최초 문서화
- 관련 파일: `js/common.js`, `js/data.js`, `js/pages/alerts.js`, `js/pages/dashboard.js`

- 관련 기능 ID: `5.3.1`, `6.2.1`, `6.2.3`, `6.4.1`
