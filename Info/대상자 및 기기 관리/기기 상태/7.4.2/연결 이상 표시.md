# 7.4.2 연결 이상 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

통신 끊김이나 데이터 미수신 같은 기기 문제를 생활 활동의 이상과 구분해 표시하는 기능입니다.

## 2. 용어 정의

- 기기 연결 이상: 기기 연결 값이 `disconnected`인 예시 상태입니다.
- 데이터 수신 안 됨: 마지막 수신 시각이 없어 장치 데이터를 확인할 수 없는 상태입니다.
- 움직임 미감지: 데이터는 수신되었지만 움직임 이벤트가 없다는 별도 생활 상태입니다.

## 3. 개념 설명

공통 상태 문구는 기기 연결 이상, 센서 데이터 수신 안 됨, 움직임 미감지를 서로 다른 배지로 제공합니다. 설정·대시보드·생활패턴 화면이 예시 기기와 대상자 상태를 읽어 구분해 표시합니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 예시 데이터에서 연결 이상·수신 없음·움직임 미감지를 다른 문구와 스타일로 구분합니다.
- 제한: 실제 통신 장애 탐지, 장애 발생 시각 계산, 실시간 알림 및 장치 진단은 없습니다.
- 주요 코드 경로: `js/common.js`(상태 문구), `js/data.js`, `js/pages/settings.js`, `js/pages/dashboard.js`, `js/pages/pattern.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 상태 문구 구분은 구현되었으나 실제 장치 장애 탐지는 미구현이라는 동작과 제한을 기록
- 변경 이유: 생활 이상과 기기 문제를 혼동하지 않도록 현재 표시 기준을 최초 문서화
- 관련 파일: `js/common.js`, `js/data.js`, `js/pages/settings.js`, `js/pages/dashboard.js`, `js/pages/pattern.js`

- 관련 기능 ID: `3.3.2`, `7.4.1`, `8.2.2`
