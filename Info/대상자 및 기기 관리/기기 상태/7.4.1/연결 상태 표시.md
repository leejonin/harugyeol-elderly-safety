# 7.4.1 연결 상태 표시

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

센서와 실내 스피커의 연결 상태 및 마지막 데이터 수신 시각을 웹 화면에 표시하는 기능입니다.

## 2. 용어 정의

- 연결 상태: 예시 기기의 `connection` 값과 마지막 수신 시각을 조합한 화면 상태입니다.
- 마지막 수신 시각: 해당 기기에서 가장 최근 데이터를 받은 것으로 표시하는 예시 시각입니다.

## 3. 개념 설명

설정 화면과 대시보드는 `connected`, `disconnected` 및 `lastReceivedAt` 값을 읽어 연결됨, 연결 이상 또는 수신 없음으로 표시합니다. 현재 값은 실제 장치 상태를 조회한 것이 아니라 시드 데이터입니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 예시 센서·스피커의 연결 상태와 마지막 수신 시각을 대상자별로 표시합니다.
- 제한: 장치 상태 폴링, 연결 확인 API, 실시간 갱신 및 장애 복구 처리는 없습니다.
- 주요 코드 경로: `js/data.js`(예시 상태), `js/pages/settings.js`, `js/pages/dashboard.js`, `js/pages/pattern.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 연결 상태 표시는 구현되었으나 실제 장치 상태가 아닌 예시 값이라는 동작과 제한을 기록
- 변경 이유: 화면 표시와 실시간 기기 연동을 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/settings.js`, `js/pages/dashboard.js`, `js/pages/pattern.js`

- 관련 기능 ID: `3.3.1`, `7.3.3`, `7.4.2`
