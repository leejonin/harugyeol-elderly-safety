# 7.3.3 기기 정보 관리

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

기기 종류, 설치 위치, 표시 이름과 연결 대상자를 확인하고 수정하는 기능입니다.

## 2. 용어 정의

- 기기 정보: 기기 ID, 유형, 표시 이름, 설치 위치, 대상자 및 연결 상태 정보입니다.
- 표시 이름: 설정과 상태 화면에서 사용자가 구분할 수 있도록 보여주는 기기 명칭입니다.

## 3. 개념 설명

설정 화면은 접근 가능한 대상자의 예시 기기를 조회하고 표시 이름과 설치 위치를 수정합니다. 기기 유형과 연결 대상자는 표시만 간접적으로 확인할 수 있으며 변경할 수 없습니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 예시 기기의 종류·대상·위치·이름을 조회하고 위치와 이름을 `localStorage`에 저장합니다.
- 제한: 기기 종류 변경, 대상자 재연결, 삭제, 서버 저장 및 실제 장치 설정 반영은 없습니다.
- 주요 코드 경로: `settings.html`, `js/pages/settings.js`, `js/data.js`, `js/common.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 이름·위치 수정은 동작하지만 유형·대상 연결 및 실제 장치 관리는 미구현이라는 내용을 기록
- 변경 이유: 현재 수정 가능한 기기 정보 범위를 명확히 하기 위해 최초 문서화
- 관련 파일: `settings.html`, `js/pages/settings.js`, `js/data.js`, `js/common.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `7.3.3`
- 관련 기능 ID: `7.3.1`, `7.3.2`, `7.4.1`
