# 7.3.2 스피커 등록·연결

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

음성 안부 확인에 사용할 실내 스피커를 대상 어르신에게 등록하고 연결하는 기능입니다.

## 2. 용어 정의

- 실내 스피커: 어르신에게 안부 질문을 전달하고 응답 연동에 사용할 외부 장치입니다.
- 브라우저 TTS: 웹 채팅 답변을 브라우저가 읽는 기능으로 실내 스피커 등록과 관계없습니다.

## 3. 개념 설명

스피커 식별자와 설치 위치를 등록하고 대상자 및 통신 채널에 연결해야 합니다. 현재 `speaker` 유형의 예시 기기만 존재하며 이름·위치 수정 외의 등록·연결 처리는 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 예시 스피커의 이름, 위치, 연결 상태와 마지막 수신 시각을 화면에 표시합니다.
- 제한: 신규 등록, 장치 인증, 실내 스피커 통신, 질문 실행 및 응답 수신이 모두 미연동입니다. `10.1.2`의 브라우저 TTS는 이 기능을 대체하지 않습니다.
- 주요 코드 경로: `js/data.js`(예시 스피커), `js/pages/settings.js`, `js/pages/dashboard.js`
- 핵심 등록·연결 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 예시 스피커 표시는 있으나 실제 등록·연결은 없고 브라우저 TTS와 별개라는 내용을 기록
- 변경 이유: 장치 연동 범위를 명확히 하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/settings.js`, `js/pages/dashboard.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `7.3.2`
- 관련 기능 ID: `5.1.1`, `5.2.1`, `7.3.3`, `7.4.1`, `10.1.2`
