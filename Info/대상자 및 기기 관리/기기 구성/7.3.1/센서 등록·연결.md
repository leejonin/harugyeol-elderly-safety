# 7.3.1 센서 등록·연결

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

어르신별 스마트 플러그·문 열림·움직임 센서를 등록하고 데이터 수신 경로에 연결하는 기능입니다.

## 2. 용어 정의

- 센서 등록: 기기 식별자, 종류, 위치와 대상자를 시스템에 저장하는 절차입니다.
- 실제 연결: 센서 장치에서 웹 또는 서버로 데이터를 송수신할 수 있는 상태입니다.

## 3. 개념 설명

센서 정보를 입력하고 대상자에 연결한 뒤 장치 통신을 설정해야 합니다. 현재는 `devices` 배열의 예시 센서를 화면에 표시하고 이름·위치를 수정할 뿐 신규 등록이나 통신 연결을 수행하지 않습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 예시 센서의 종류, 위치, 연결 상태와 마지막 수신 시각을 표시합니다.
- 제한: 센서 추가, 장치 인증, 대상자 연결, 데이터 수신 설정 및 실제 통신이 모두 미연동입니다.
- 주요 코드 경로: `js/data.js`(예시 기기), `js/pages/settings.js`, `js/pages/pattern.js`
- 핵심 등록·연결 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 예시 센서 표시와 정보 수정은 있으나 센서 등록·실연결은 미구현이라는 내용을 기록
- 변경 이유: 화면의 기기 목록을 실제 장치 연결로 오인하지 않도록 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/settings.js`, `js/pages/pattern.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `7.3.1`
- 관련 기능 ID: `3.1.1`, `3.1.2`, `3.1.3`, `7.3.3`, `7.4.1`
