# 7.1.2 어르신 정보 조회·수정

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

등록된 어르신 정보를 조회하고 필요한 항목을 수정하는 기능입니다.

## 2. 용어 정의

- 대상자 정보: 어르신의 이름, 출생연도, 주소 및 상태 관련 예시 데이터입니다.
- 접근 범위: 로그인한 시연 사용자에게 `elderIds`로 연결된 대상자 목록입니다.

## 3. 개념 설명

설정 화면은 접근 가능한 대상자만 조회해 이름을 표시하고 주소와 출생연도를 입력 폼으로 제공합니다. 저장하면 해당 값을 브라우저 `localStorage`에 반영합니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 접근 가능한 예시 어르신의 주소·출생연도를 조회·수정하고 같은 브라우저에 저장합니다.
- 제한: 이름과 대상자 ID 등 전체 정보 수정, 서버 저장, 입력 이력 및 운영 권한 검증은 없습니다.
- 주요 코드 경로: `settings.html`, `js/pages/settings.js`, `js/data.js`, `js/common.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 주소·출생연도 중심의 시연 조회·수정은 동작하지만 전체 정보 및 서버 관리는 미구현이라는 내용을 기록
- 변경 이유: 실제 수정 가능한 항목과 저장 범위를 명확히 하기 위해 최초 문서화
- 관련 파일: `settings.html`, `js/pages/settings.js`, `js/data.js`, `js/common.js`
