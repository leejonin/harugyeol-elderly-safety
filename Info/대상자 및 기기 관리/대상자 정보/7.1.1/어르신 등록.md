# 7.1.1 어르신 등록

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

안전관리 대상 어르신의 기본 정보를 새로 등록하는 기능입니다.

## 2. 용어 정의

- 대상자: 하루결에서 생활 상태와 대응 정보를 관리할 어르신입니다.
- 기본 정보: 이름, 출생연도, 주소 및 대상자 식별자 등 관리에 필요한 정보입니다.

## 3. 개념 설명

새 대상자 정보를 입력하고 고유 ID를 부여해 저장한 뒤 사용자·연락처·기기와 연결할 수 있어야 합니다. 현재 대상자 목록은 시드 데이터로만 제공되고 설정 화면에는 신규 등록 폼이나 추가 처리가 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 미리 작성된 예시 대상자 정보를 조회하고 일부 항목을 수정할 수 있습니다.
- 제한: 대상자 생성, 필수값 검증, 중복 검사, 서버 저장 및 사용자 연결이 없습니다.
- 주요 코드 경로: `js/data.js`(예시 대상자), `js/pages/settings.js`(기존 정보 수정)
- 핵심 등록 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 기존 예시 정보 수정과 별개로 신규 어르신 등록은 미구현이라는 동작과 제한을 기록
- 변경 이유: 조회·수정 기능과 신규 등록 기능을 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/pages/settings.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `7.1.1`
- 관련 기능 ID: `7.1.2`, `7.2.3`, `7.3.1`
