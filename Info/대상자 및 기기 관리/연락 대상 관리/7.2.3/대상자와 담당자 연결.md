# 7.2.3 대상자와 담당자 연결

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

어르신별 가족·보호자와 관리 담당자를 연결하고 그 관계를 관리하는 기능입니다.

## 2. 용어 정의

- 대상자 연결: 보호자·기관·사용자 데이터에 대상자 ID를 연결하는 관계입니다.
- 담당자: 가족·보호자 또는 관리기관 사용자처럼 대상자를 조회·확인할 주체입니다.

## 3. 개념 설명

현재 시드 데이터는 보호자·기관의 `elderId`와 사용자의 `elderIds`로 고정 관계를 표현합니다. 이 관계를 새로 선택하거나 변경하는 관리 화면과 저장 처리는 없습니다.

## 4. 현재 구현 상태

- 상태: **미구현**
- 실제 동작: 코드에 미리 지정된 연결 관계를 이용해 연락처와 접근 대상자를 필터링합니다.
- 제한: 관계 생성·변경·해제, 담당자 선택, 권한 검증 및 서버 저장이 없습니다.
- 주요 코드 경로: `js/data.js`(고정 관계), `js/common.js`(접근 대상 필터), `js/pages/settings.js`(연결된 정보 표시)
- 핵심 연결 관리 구현 경로: 없음

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 고정 예시 관계는 사용하지만 사용자가 대상자와 담당자를 연결하는 기능은 미구현이라는 내용을 기록
- 변경 이유: 데이터에 관계가 존재하는 것과 관계 관리 기능을 구분하기 위해 최초 문서화
- 관련 파일: `js/data.js`, `js/common.js`, `js/pages/settings.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `7.2.3`
- 관련 기능 ID: `7.1.1`, `7.2.1`, `7.2.2`, `8.1.2`
