# 7.2.1 가족·보호자 등록

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

확인 요청을 받을 가족·보호자의 연락 정보를 등록하고 수정하는 기능입니다.

## 2. 용어 정의

- 보호자 정보: 보호자 이름, 대상자 관계, 연락처 및 연결된 대상자 ID입니다.
- 보호자 추가(시연): 첫 번째 접근 가능 대상자에 기본값으로 새 보호자 객체를 만드는 기능입니다.

## 3. 개념 설명

설정 화면은 예시 보호자의 관계와 연락처를 수정할 수 있습니다. 추가 버튼은 이름이 `새 보호자`인 객체를 첫 번째 접근 가능 대상자에 생성하지만 이름과 연결 대상자를 입력·선택하는 등록 절차는 없습니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 예시 보호자 조회, 관계·연락처 수정 및 제한적인 시연용 추가가 `localStorage`에서 동작합니다.
- 제한: 이름 입력, 대상자 선택, 연락처 검증, 삭제, 서버 저장 및 실제 알림 수신자 등록은 없습니다.
- 주요 코드 경로: `settings.html`, `js/pages/settings.js`, `js/data.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 제한적인 시연 추가·수정은 있으나 완전한 보호자 등록과 외부 알림 연동은 없다는 내용을 기록
- 변경 이유: 추가 버튼의 실제 처리 범위를 명확히 하기 위해 최초 문서화
- 관련 파일: `settings.html`, `js/pages/settings.js`, `js/data.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `7.2.1`
- 관련 기능 ID: `6.2.1`, `7.2.3`
