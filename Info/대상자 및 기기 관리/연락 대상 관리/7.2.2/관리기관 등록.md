# 7.2.2 관리기관 등록

- 문서 초기 생성 일시: 2026-10-15 12:04 KST
- 문서 수정 일시: 2026-10-15 12:04 KST

## 1. 개요

후속 대응을 요청할 관리기관의 연락 정보를 등록하고 관리하는 기능입니다.

## 2. 용어 정의

- 관리기관 정보: 기관 이름, 연락처 및 연결된 대상자 ID로 구성된 정보입니다.
- 시연 기관: `js/data.js`에 미리 작성된 복지센터·요양시설 예시입니다.

## 3. 개념 설명

설정 화면은 접근 가능한 대상자와 연결된 예시 기관을 조회하고 연락처를 수정할 수 있습니다. 신규 기관 추가, 기관명 수정, 대상자 연결 변경 기능은 없습니다.

## 4. 현재 구현 상태

- 상태: **구현 중**
- 실제 동작: 예시 관리기관과 연락처를 표시하고 연락처를 같은 브라우저의 `localStorage`에 저장합니다.
- 제한: 신규 등록, 기관명·연결 대상 변경, 삭제, 연락처 검증, 서버 저장 및 실제 기관 연결 요청은 없습니다.
- 주요 코드 경로: `settings.html`, `js/pages/settings.js`, `js/data.js`

## 5. 수정한 작업 전후 내용

- 수정 전: 기능 문서 미작성
- 수정 후: 기존 예시 기관의 연락처 수정만 가능하고 완전한 등록·연결은 미구현이라는 내용을 기록
- 변경 이유: 연락처 수정과 신규 기관 등록의 구현 범위를 구분하기 위해 최초 문서화
- 관련 파일: `settings.html`, `js/pages/settings.js`, `js/data.js`

## 6. 기능 ID 및 관련 기능 ID

- 기능 ID: `7.2.2`
- 관련 기능 ID: `6.3.1`, `7.2.3`
